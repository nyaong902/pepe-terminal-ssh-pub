# v2.2.3

## 자동 업데이트 설치 안정성

- 다른 PC(관리자 권한/그룹정책 환경이 다른 회사 PC 등)에서 앱 내 자동 업데이트로 "재시작하여 설치"를 눌렀을 때 설치 창이 아예 뜨지 않던 문제 수정. 수동으로 설치 파일을 직접 실행하면 항상 정상 동작했던 것과 달리, 자동 업데이트는 NSIS 자체 내장 권한 상승(자기 자신을 다시 실행) 방식에 의존하고 있었는데 이 방식이 환경에 따라 불안정했음
- 빌드에는 이미 포함돼 있던 전용 권한 상승 도구(`elevate.exe`)를 자동 업데이트 설치 시 실제로 사용하도록 설정(`packElevateHelper`) 추가 — 이 값이 빠져 있어서 지금까지 한 번도 쓰이지 않고 있었음

## 세션 편집 — 글꼴 실시간 반영

- 사이드바에서 세션을 편집해 글꼴을 바꿔도, 이미 열려 있는 해당 세션의 탭에는 반영되지 않고 탭을 새로 열어야만 바뀌던 문제 수정. X11 forwarding 설정 변경 때만 있던 실시간 반영 로직을 글꼴/테마/스크롤백/커서 스타일까지 확장
