# v2.2.17

## v2.2.16 되돌림 — 자동 업데이트 중 커스텀 페이지 다시 숨김

v2.2.16에서 "실제 원인은 autoInstallOnAppQuit 중복 실행이었으니 커스텀 페이지를 자동 업데이트 중에도 보여줘도 된다"고 바꿨는데, 실제로 테스트해보니 지금까지 항상 정상이던 PC에서도 설치 창이 다시 안 뜨는 게 재현됐습니다. 즉 인터랙티브 페이지 자체도 여전히 자동 업데이트 흐름에서 문제를 일으킵니다.

v2.2.4~v2.2.15에서 검증된 동작(자동 업데이트 시 두 커스텀 페이지 모두 무조건 건너뛰기)으로 되돌립니다. 자동 업데이트 중에는 이전 설치 때 레지스트리에 저장해둔 선택값을 그대로 재적용합니다.
