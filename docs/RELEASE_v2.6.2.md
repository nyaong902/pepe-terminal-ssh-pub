# v2.6.2

여러 줄 붙여넣기 창에 **열 편집**이 생겼습니다. AI Chat 쪽은 **창을 옮겨도 진행 상태가 그대로
따라오도록** 다듬었습니다.

## 📋 여러 줄 붙여넣기 — 열 편집

파일 목록을 붙여넣고 **모든 줄 앞에 같은 명령을 한 번에** 넣을 수 있습니다(Notepad++ 식
열 편집).

- **Alt + 드래그** = 열(네모) 선택
- **Ctrl + 클릭** = 커서 추가

편집기 기본값은 `Alt+Shift+드래그` 였는데, 끄는 동안 단어 선택이 함께 일어나 쓰기 불편했습니다.
커서 추가를 `Ctrl` 로 옮겨 `Alt` 를 비웠습니다.

**줄 번호 칸을 본문과 다른 색**으로 두었습니다. 같은 바탕이라 어디까지가 내용인지 구분이
되지 않았습니다. 창의 색은 **앱 테마를 따라갑니다** — 다른 창에서 테마를 바꾸면 이 창도 같이
바뀝니다.

창은 **편집기까지 준비된 뒤에** 뜹니다. 덜 된 화면이 잠깐 보였다가 바뀌던 어색함을 없앴습니다.
한 번 띄운 창은 닫아도 **숨겨 두었다 다시 쓰므로**, 두 번째부터는 곧바로 열립니다.

위치·크기 조절·끌기, `Esc` 취소 / `Ctrl+Enter` 붙여넣기, 창이 떠 있을 때 다시 붙여넣으면
누적/교체하는 동작은 그대로입니다.

## 💬 AI Chat

### 진행 중에 창을 옮기면 중단 버튼이 사라지던 문제

응답을 기다리는 동안 사이드바에서 워크스페이스 탭이나 분리 창으로 옮기면, 내용은 따라오는데
**중단 버튼도 끼어들기 안내도 도구 진행 줄도 뜨지 않았습니다.** 옮겨 간 쪽은 그 요청을 보낸
적이 없어서 "진행 중" 이라는 것을 몰랐습니다.

이제 그 대화를 여는 즉시 진행 상태를 이어받습니다. 중단도 그대로 동작합니다.

### 다른 화면으로 옮기면 대화 이력이 밑에 딸려 나오던 문제

이력 목록을 켠 채로 **스티커 메모·메신저·작업일지**로 넘어가면, 그 목록 아래에 대화 이력이
그대로 붙어 나왔습니다. 이력은 AI Chat 의 것이므로 그때만 보이게 했습니다. 켜 둔 상태는
그대로라, AI Chat 으로 돌아오면 다시 보입니다.

### 메시지 삭제가 묻힐 수 있던 문제

같은 대화를 두 창이 동시에 들고 있을 때, 메시지를 지운 직후 **2초 안에** 다른 창이 저장하면
그 삭제가 조용히 무시될 수 있었습니다. 어느 사본을 살릴지 고르는 기준에서 시간에 기댄 어림을
걷어내고, **"일부러 줄인 편집" 을 명시적으로 표시**하도록 바꿨습니다. 삭제는 언제 저장되든
반영됩니다.
