# v2.5.5

**AI Chat 을 워크스페이스 탭에서 넓게 씁니다.** 그리고 두 PC 를 백업으로 오가며 쓸 때 한쪽
작업이 조용히 사라지던 문제와, 망이 끊겼다 돌아올 때 재접속이 제대로 되지 않던 문제를
고쳤습니다.

## 🤖 AI Chat — 워크스페이스 탭

사이드바에만 있던 AI Chat 을 **워크스페이스 탭**으로 열 수 있습니다.

- 여는 곳 넷 — `메뉴 > 도구`, `워크스페이스 바 +  > 워크스페이스`, 명령 팔레트,
  그리고 패널 안의 **`🤖 AI Chat` 뷰 탭 우클릭 → 워크스페이스로 이동**
- 탭에는 **AI Chat 만** 들어갑니다. 메신저·작업일지·스티커메모는 사이드바에 그대로 남습니다
- 탭이 열려 있는 동안 사이드바에서는 AI 가 사라지고, 탭을 닫으면 돌아옵니다 —
  같은 기능이 두 곳에 보이면 어느 쪽이 무엇인지 헷갈립니다
- 이미 열려 있으면 새로 만들지 않고 그 탭으로 이동합니다

### 대화이력을 옆에 두고 보기

폭이 넉넉하면 **왼쪽 대화이력 + 오른쪽 대화내용**으로 나란히 놓입니다.

- 워크스페이스 탭은 항상, 사이드바는 **1000px 이상으로 넓혔을 때**. 좁으면 예전처럼
  이력이 대화를 덮습니다(180px 을 이력에 내주면 대화를 읽을 수 없습니다)
- 이력과 대화 사이 경계를 **드래그해 폭 조절**(더블클릭 = 기본값 300px). 폭은 기억됩니다.
  창이 좁아도 대화 쪽 320px 은 항상 남깁니다
- 대화를 골라도 목록이 그대로 있습니다 — 예전에는 하나 고르면 목록이 닫혀 다음 대화를
  고를 수 없었습니다

### 창을 분리해서 쓸 때

AI Chat 탭을 **창으로 분리하면 `SSH 컨텍스트` 목록이 비어 있었습니다.** 그 창에는 터미널이
하나도 없고 연결 상태도 창마다 따로 들고 있어서, 자기 창만 훑던 목록이 늘 비었습니다. SSH
연결 자체는 앱 본체가 들고 있으니 어느 창에서든 쓸 수 있어야 맞습니다 — 이제 본체가 아는
목록을 받아옵니다.

### 대화이력 행 정리

버튼(공유·핀·복사·이름변경·삭제)이 자리를 차지해 제목이 절반쯤 잘렸습니다. 이제 **마우스를
올릴 때만** 행 오른쪽에 겹쳐 나타나고, 평소에는 제목이 폭을 다 씁니다. 이름을 고치는 중에는
버튼이 뜨지 않습니다.

## 🐙 GitHub Copilot CLI 지원

에이전트로 **Copilot** 이 추가됐습니다(기존 에이전트는 그대로).

- 로그인해 둔 `gh auth token` 을 그대로 씁니다 — `copilot login` 을 따로 하지 않아도 됩니다
  (실패하면 토큰을 직접 입력)
- 모델 선택칸이 없습니다. Copilot 에 모델 목록 API 가 없어 `--model auto` 로 맡깁니다

## 💾 백업 — 두 PC 를 오가도 작업이 사라지지 않게

두 PC 를 백업으로 동기화해 쓰면, 업로드/다운로드가 **무조건 덮어쓰기**여서 나중에 동기화한
PC 가 그 사이 다른 PC 에서 한 작업을 조용히 지웠습니다(두 대로 실제로 쓰다 나온 제보).

- 세션/폴더와 AI 대화 이력을 **id + 수정시각으로 병합**합니다 — 항목별로 더 최근에 손댄
  쪽이 남습니다
- 삭제는 **삭제 기록(tombstone)** 으로 추적합니다. 다른 PC 의 옛 스냅샷이 다시 올라와도
  일부러 지운 항목이 되살아나지 않습니다. 반대로 같은 id 를 더 최근에 고쳤다면 그쪽이 이깁니다

## 🔌 SSH 재접속

연결이 끊긴 뒤 **연결될 때까지 자동으로 재시도**합니다. 탭은 사용자가 닫을 때만 닫힙니다.

- 간격은 3 → 5 → 8 → 13 → 20 → 30초로 늘어납니다. 진행은 한 줄에서 **1초에 점 하나씩
  10개까지 찍고 다시 처음부터** 돌며, 같은 오류 문구를 반복해 찍지 않습니다
- 고친 것 — 회차가 계속 "1번째"로 되돌아가고 1~2초마다 재시도하던 문제,
  그리고 **재접속이 성공한 직후 다시 끊기던** 문제(뒤늦게 죽은 옛 연결이 방금 붙은 세션을
  지우고 있었습니다. 워커가 죽은 연결에 명령을 보내다 크래시하는 경로도 함께 막았습니다)

## 🗄 DB 워크스페이스 — 행 수 제한 해제

조회/추출이 **2000행에서 잘렸고**, 상한을 0 으로 바꿀 수도 없었습니다(0 을 넣으면 1 이 됐습니다).

- 상한을 직접 지정할 수 있고(최대 1,000,000), **`0` 은 제한 없음**입니다
- 데이터 추출은 가져온 행을 그대로 내보내므로, 조회 상한이 곧 추출 상한이었습니다

> 무제한은 0 을 명시할 때만 동작합니다. 결과 그리드는 가상 스크롤이라 행이 많아도 그리기는
> 버티지만, 조회한 행 전체가 메모리에 올라옵니다. 기본값(200)은 그대로입니다.

## 그 밖에

- **옵션 창이 파일트리에 가리던 문제** — 파일트리/사이드바 패널이 옵션 창보다 위에 그려져
  투과된 것처럼 보였습니다(z-index 1 차이)
- **자동 백업 설정 저장** — 업로드 주기를 바꾸고 아래 `저장` 을 눌러도 반영되지 않았습니다.
  이제 두 버튼(전용 `자동 백업 설정 저장` / 옵션 아래 `저장`) 어느 쪽을 눌러도 저장되고,
  주기를 키보드로 고칠 수 있으며(예전엔 0 이 1 로 바뀌고 캐럿이 튀었습니다), 저장 시각이
  함께 표시됩니다. 업로드/다운로드가 끝나면 토스트로 알려 창을 닫아도 결과를 볼 수 있습니다
- **앱 구동 직후 mermaid 가 코드로 남던 문제** — 설치 확인이 끝나 대화 화면이 만들어지는
  순간을 렌더 패스가 놓쳐 스캔 대상이 하나도 없었습니다
- **채팅 글꼴 크기**(옵션 > 터미널)가 워크스페이스 탭에도 적용됩니다
- **대화 지우기(🗑) 전에 확인**을 묻습니다 — 한 번 잘못 누르면 되돌릴 수 없었습니다
- **mac 에서 모델 목록**이 Sonnet 5 등 최신 모델을 못 보여주던 문제 — macOS 는 토큰을
  키체인에 두는데 파일만 읽고 있었습니다
- **개발자 도구 버튼**은 다시 `메뉴 > 도구 > 개발자 도구 버튼 표시` 로 켭니다(새 설치는 숨김)
- **런타임 로그 창**을 제목줄로 잡아 옮길 수 있습니다
- 세션을 **새 워크스페이스로 열 때** 로컬 셸을 함께 띄우지 않습니다. 로컬 셸 미니탭 이름도
  `Local Shell` 이 아니라 실제 셸 이름(예: Windows PowerShell)으로 나옵니다
- 옵션에서 **디버그 탭**을 제거했습니다
- **연결 목록이 실제 연결과 어긋나던 문제** — 앱은 접속/종료 이벤트로만 "지금 붙어 있는
  세션" 장부를 적었는데, SSH 는 인증이 끝난 뒤 셸이 열리기까지 시간이 걸립니다(점프 호스트가
  있으면 수 초). 그 사이에 목록을 물어보면 아직 등록 전이라 방금 적은 항목이 지워졌고, 다시
  넣어주는 곳이 없어 **접속돼 있는데도 목록이 비는** 상태로 굳었습니다. 이제 물어볼 때마다
  실제 연결표로 장부를 바로잡습니다. 텔넷 세션이 붙자마자 이 목록에서 빠지던 것도 함께
  고쳤습니다
