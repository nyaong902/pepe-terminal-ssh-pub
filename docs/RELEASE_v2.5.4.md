# v2.5.4

**설정과 기록을 클라우드에 백업합니다.** 그리고 CDR 로그 분석에 "이 통화가 정상이었는지"
판별이 붙었습니다.

## ☁ 백업 / 복원

옵션에 `백업` 탭이 생겼습니다. 앱이 들고 있는 데이터를 **종류별로 골라** 클라우드에 올리고,
다른 PC 에서 내려받을 수 있습니다.

- 고를 수 있는 항목 — 세션/폴더, AI 대화 기록, UI 설정, VPN 자격증명, 브라우저 자격증명,
  메신저, 미디어 최근 목록, 그 밖의 도구 설정. 하나씩 또는 `전체 선택` 으로
- 저장 위치는 **Pepe-Box 에 연결해둔 계정**(Google Drive / Dropbox / OneDrive)의
  `PEPE-TERMINAL-SSH` 폴더입니다. 클라우드 계정 자체의 로그인 토큰은 백업에서 제외합니다
- **암호를 걸어 올립니다** — AES-256-GCM(암호는 scrypt 로 키 유도). 암호는 옵션 창이 열려
  있는 동안만 메모리에 있고 어디에도 저장되지 않습니다. **잊으면 복원할 수 없습니다**
- 내려받으면 로컬 파일을 덮어쓰고 앱을 다시 시작합니다(복원한 데이터가 적용되도록)

### 자동 백업

계정·항목·주기를 한 번 정해두면 그 뒤로는 알아서 올라갑니다 — 창도 뜨지 않고 암호를 다시
묻지도 않습니다.

- 무인 실행에는 암호가 앱을 껐다 켜도 남아 있어야 하므로, **OS 키체인**(`safeStorage`)에
  따로 보관합니다. 수동 백업이 쓰는 "창이 열려 있는 동안만" 암호와는 별개입니다.
  저장된 암호는 화면으로 되돌려주지 않고 "설정됨" 여부만 알려줍니다
- 주기에 맞춘 타이머가 아니라 **10분마다 확인**하는 방식입니다 — 앱을 계속 켜두지 않으면
  주기 타이머는 그 회차를 조용히 건너뜁니다. 앱을 켤 때 놓친 회차를 따라잡고, 끌 때도 한 번 시도합니다

## 🔍 CDR 로그 분석 — 통화가 정상이었는지 판별

CLOG 를 변환하면 표 왼쪽에 열 세 개가 자동으로 붙습니다.

```
서비스            1차(CLOG)              2차(CDR)
착신전환 사용     정상                    정상 확인
일반통화          미완료(통화중(Busy))    CDR 값 상이
```

- **서비스** — 부가서비스(착신전환·단축번호 등)와 지능망 서비스 사용 내역을 읽어 무슨 통화였는지
- **1차(CLOG)** — 호 처리 흐름(시도 → Setup → Alert → 응답 → 종료)이 끝까지 갔는지, 통화시간과
  종료 사유가 맞는지. 과금번호·미디어 이상도 함께 봅니다
- **2차(CDR)** — 같은 통화의 CDR 을 찾아 값이 일치하는지 대조. CDR 을 안 넣었으면 `CDR 미수집`
- 상단에 `정상 n · 조작 n · 미완료 n · 실패 n` 요약이 뜨고, **서비스/1차/2차 로 검색**할 수 있습니다
- 1차 판정 칸에 마우스를 올리면 **왜 그렇게 판정했는지** 호 처리 흐름이 뜹니다
- Clog Excel 맨 앞에 판정 4열이 함께 나갑니다

## 🙈 필드 숨기기

Clog 는 필드가 121개, CDR 도 36개라 가로로 한참 밀어야 원하는 값이 나왔습니다.
각 필드 이름 옆 체크박스를 끄면 그 열이 접힙니다.

- 완전히 없애지 않고 체크박스만 남깁니다 — 없애 버리면 다시 켤 자리를 찾을 수 없습니다
- 상단 `숨긴 열 n개 · 모두 표시` 로 한 번에 되돌립니다

## 💬 AI 챗

- **끼어들기(스티어링) 뒤 대화가 멈추던 근본 원인.** 도구를 호출할 때마다 "대화가 끝난 것"으로
  처리돼 "생각 중" 표시가 중간에 사라졌습니다. 도구 호출은 *한 번의 왕복이 끝난 것*일 뿐이라고
  양쪽(화면·백엔드)에서 같게 판정하도록 고쳤습니다
- **`Prompt is too long` 으로 조용히 죽던 문제.** claude+ 가 살아 있는데도 요청마다 전체 대화를
  다시 밀어넣어 컨텍스트가 쌓였습니다. 이제 살아 있으면 재주입하지 않습니다.
  그리고 오류로 끝난 경우 **오류 문구를 말풍선으로 보여줍니다** — 지금까진 아무 말 없이 사라졌습니다

## 🖥 SSH

- **현재 경로 자동 추적이 서버에 따라 틀리던 문제** — `/root` 와 실제 경로 사이를 왕복하거나,
  로그인 셸이 아닌 엉뚱한 프로세스의 경로를 잡았습니다. 다른 프로세스의 `/proc` 열람을 막는
  서버, `etimes` 를 지원하지 않는 구버전 procps 서버에서도 되도록 고쳤습니다
- **어떤 서버에서는 파일트리가 `cd` 를 전혀 따라가지 않던 문제.** 접속 경로가 두 갈래인데
  한쪽에서만 경로 추적이 시작되고 있었습니다. 그 경로에서는 프롬프트 해석이 유일한 수단이
  되는데, 프롬프트에 디렉터리 **이름만** 찍는 서버(`[root@host KVM]#`)는 그것으로 경로를
  알 수 없어 아무것도 따라가지 못했습니다. 양쪽 모두 추적을 시작하도록 맞췄습니다
- **`cd` 반영이 한 박자 늦던 것** — 경로를 주기적으로 확인하는 방식이라 그 주기만큼 기다렸습니다.
  확인 횟수는 그대로 두고, **프롬프트가 바뀐 순간**(명령이 끝난 순간)에 다음 확인을 앞당겨
  바로 반영합니다. 타이핑 중이거나 디렉터리가 그대로면 앞당기지 않습니다

## 📁 파일 전송

- **일괄 전송 창이 전송 중에는 닫히지 않던 문제.** 큰 전송을 걸면 끝날 때까지 창이 멈춘 것처럼
  보였습니다. 전송은 창과 무관하게 돌아가므로 닫아도 계속되고, 다시 열면 진행 상황이 그대로 보입니다
- **여러 파일을 올릴 때 "모두 적용" 이 무시되던 문제**(같은 이름 충돌 처리)
- 세션 목록에서 **폴더를 여러 개 선택해 옮기면 하나만 옮겨지던 문제**, 폴더를 지우면 그 안의
  세션이 목록에서 사라지던 문제

## 🚀 그 밖에

- **앱을 켤 때 안 쓰는 화면 두 개를 만들지 않습니다** — 창 스냅 미리보기는 창을 끌기 시작할 때
  만들고, 사내 메신저는 그 모드를 쓸 때만 붙입니다. 프로세스 6개 → 4개, 메모리 72MB 절감
  (회사 메신저를 쓰는 설정이면 예전과 동일하게 시작부터 붙습니다)
- 워크스페이스 탭을 `Shift+클릭` 하면 확인 없이 바로 닫힙니다(가운데 클릭과 같음)
- 스티커 메모에서 `Shift+Enter` 로 줄을 바꾸면 안내 문구가 글자와 겹쳐 보이던 문제
