# v2.3.0

## 탭을 드래그하면 앱이 완전히 멈추는(강제종료 필요) 버그 수정

탭바(`.tab-bar-row`)는 타이틀바 드래그 영역(`-webkit-app-region: drag`)인데, 그 안에서 HTML5
네이티브 드래그(`draggable`)로 탭을 옮기려 하면 Windows에서 OS 창-드래그와 충돌해 렌더러가
완전히 멈춰버리는(CPU 0%, 강제종료해야 함) 문제가 있었습니다. Electron 자체의 알려진 버그로,
탭 재정렬/새 창으로 분리하는 드래그 로직을 네이티브 HTML5 DnD 대신 `mousedown`/`mousemove`/
`mouseup` 기반 자체 구현으로 완전히 교체해 근본적으로 해결했습니다.

## 파일 전송 탭 안정성 개선

- **창 분리/재합침 시 불필요한 재접속 제거**: 파일전송 탭을 다른 창으로 분리했다가 다시
  합칠 때, 이미 연결돼 있던 SFTP 세션을 "무효할 수 있다"고 보고 매번 lazy-remote(재접속 필요)로
  강등시키던 버그를 고쳤습니다 — termId가 실제로 살아있으면 그대로 유지합니다.
- **목록이 비었다가 다시 채워지는 깜빡임 제거**: 창 분리/재합침으로 파일전송 패널이 재마운트될
  때 마지막으로 불러온 파일 목록을 캐싱해 즉시 보여주고, 백그라운드에서 조용히 새로고침하도록
  했습니다. 새로고침 중에도 "로딩 중" 화면이 기존 목록을 가리지 않습니다.
- **ClearCase 동적 뷰(`/vobs/...`) 파일 다운로드/업로드 실패 수정**: 경로 변환이 최상위
  전송 함수 진입 시점이 아니라 그 이후 단계에서만 이뤄져, 사전 상태 확인 단계에서부터
  "No such file"로 실패하던 문제를 고쳤습니다.
- 탭이 `display:none`으로 숨겨졌다가 다시 보일 때 컨테이너 크기가 순간 0이 되며 파일 패널이
  통째로 재마운트되어 "재접속처럼 보이던" 문제 수정.

## 그 외 안정성 수정

- SSH 연결 직후 CPU가 치솟던 버그 수정 — termId가 등록되지 않은 대상(파일전송 placeholder
  로컬 셸 등)에 IPC 릴레이가 자기 자신에게 무한히 왕복하던 문제.
- 매뉴얼 뷰어에서 내부 링크를 클릭하면 존재하지 않는 경로로 창 전체가 이동해 앱이 사라지던
  크래시 수정.
- 매뉴얼 뷰어에 캡처 이미지가 안 보이던 문제 수정.
- 작업표시줄 아이콘이 패키징된 빌드에서 로드에 실패해 기본 Electron 아이콘으로 뜨던 문제 수정.
- SQL Tool 세션 편집 화면에서도 JDBC 드라이버 관리자를 열 수 있도록 추가(이전엔 접속 후에만
  가능).
- 시계 위젯: 뽀모도로 타이머가 정각보다 1틱 늦게 시작하던 문제, 시계 디자인 개선(Mondaine SBB
  스타일), 타이머 완료 알림을 OS 알림 대신 앱 내 팝업으로 변경.
- 오피스 워크스페이스: 대용량 임베드 OLE 개체가 있는 문서를 열기 전 경고 표시.
- 파일 목록의 아이콘을 네이티브 OS 아이콘 대신 확장자 기반 고정 아이콘으로 변경 — 비동기로
  불러오며 이모지에서 실제 아이콘으로 바뀌는 전환이 눈에 띄던 것을 없애고 항상 즉시 표시되도록 함.
- 화면 캡처 저장 위치를 직접 고를 수 있게 하고, 캡처 완료 시 토스트 알림(클릭하면 저장 폴더
  열기)을 추가.
