# v2.2.2

## 설치 프로그램 안정성

- 자동 업데이트로 v2.2.1을 설치할 때 "기능 선택" 페이지가 항상 건너뛰어지던 문제 수정 — `--updated` 인자 유무로 "무음 설치인지"를 판단하던 게 잘못이었음(이 앱의 자동 업데이트는 실제로 화면이 보이는 방식). NSIS가 직접 관리하는 진짜 무음 여부(`/S` 플래그)로 판단하도록 수정
- 설치 프로그램의 Windows 파일 설명(FileDescription)이 리브랜딩 이전 이름("SSH Terminal Client")으로 남아있던 것 수정 — 작업관리자에 낯선 이름으로 떠서 다른 프로그램이 멈춘 것처럼 보이던 원인
- 관리자 권한(UAC) 승인 후 설치 창이 다른 창 뒤에 숨어 안 보이던 문제 수정 — 자동 업데이트처럼 백그라운드에서 간접 실행 → UAC 승인 흐름을 탈 때, 새로 뜨는 창이 포커스를 못 받는 Windows 동작에 대한 대응(`BringToFront`) 추가
- 오피스/미디어 등 선택 해제한 대용량 기능 삭제 시, 파일 수천 개짜리 폴더(FlowChart 라이브러리 등)를 하나씩 로그 찍으며 지우던 방식 때문에 설치가 느려지던 문제 수정 — 한 번에 통째로 삭제하도록 변경
- 빌드할 때마다 `.cache`에 수백MB~수GB씩 쌓이던 산출물 폴더를 빌드 직후 자동 정리하도록 변경

## 창 분리(새 창으로 열기) 버그 수정

- 새 창으로 분리했던 워크스페이스를 다시 메인 창으로 끌어다 합치는(재도킹) 동작이 전혀 반응하지 않던 문제 수정 — "탭이 하나뿐이면 분리 금지" 가드가 재도킹 시에도 잘못 걸리고 있었음
- SIPp/오피스/미디어 워크스페이스를 새 창으로 분리하면 작업 중이던 내용이 초기화되던 문제 수정 — SIPp는 시나리오 빌더 구성과 옵션 값, 오피스는 열려 있던 문서 형식 탭, 미디어는 열려 있던 파일 목록을 새 창에서도 그대로 이어받도록 함(단, 디코딩된 오디오 버퍼나 실행 중인 통화·부하테스트처럼 프로세스에 묶인 상태까지는 옮길 수 없음)
- 커스텀 워크스페이스(여러 워크스페이스를 슬롯으로 섞어 배치한 탭)를 새 창으로 분리하면 레이아웃이 통째로 사라지던 문제 수정 — 분리 시 그리드 템플릿 정보가 아예 누락되고 있었음
- 파일전송 워크스페이스를 새 창으로 분리하면 아무 반응이 없던 문제 수정 — Electron IPC(`ipcRenderer.invoke`)가 요구하는 구조화 복제(structured clone) 조건을 만족하지 못하는 값이 섞여 있으면 에러 없이 조용히 실패하던 것을, 페이로드 전체를 JSON으로 정리해서 방지
