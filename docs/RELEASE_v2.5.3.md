# v2.5.3

**앱을 두 개 띄워도 프로세스는 한 벌만 씁니다.** 창은 그대로 두 개, 메모리는 26% 줄었습니다.

## 🪟 두 번째 창이 프로세스를 새로 만들지 않습니다

앱을 두 번 실행하면 작업 관리자에 프로세스가 6개씩 두 무리로 떴습니다. 그런데 그중 상당수가
같은 일을 하는 중복이었습니다.

| | 프로세스 | 메모리 |
|---|---|---|
| 이전 | 12개 | 715 MB |
| **지금** | **8개** | **527 MB** |
| | −4개 | **−188 MB (26%)** |

Chromium 은 브라우저 프로세스마다 GPU·네트워크 담당을 따로 둡니다. 프로세스가 갈린 이상 그
한 벌은 절대 서로 빌려 쓸 수 없으므로, **창 하나를 더 띄우려고 프로세스를 새로 만드는 것
자체가 낭비**였습니다. 이제 두 번째 실행은 이미 떠 있는 앱에 창을 하나 맡기고 사라집니다.

사라진 것은 GPU 한 벌, 메인 한 벌, 네트워크 한 벌, 그리고 창 스냅 미리보기 한 벌입니다.
새 창이 갖는 자기 화면 몫은 창이 하나 더 있는 값이라 그대로 남습니다.

- 새 창은 지금까지 탭을 떼어냈을 때 열리던 창과 같은 종류입니다 — 워크스페이스 하나로 시작합니다
- 첫 창을 닫아도 앱은 살아 있고, 남은 창이 그 자리를 이어받습니다
- 접속 주소를 인자로 실행하는 경우(`pepe://ssh…`)는 예전대로 **기존 창의 새 탭**으로 열립니다

> **알아두실 것:** 프로세스가 하나이므로 **한 창이 비정상 종료되면 모든 창이 함께 닫힙니다.**
> 예전에는 인스턴스가 갈려 있어 서로 영향이 없었습니다.
