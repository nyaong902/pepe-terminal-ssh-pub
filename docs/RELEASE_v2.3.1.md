# v2.3.1

## 탭 드래그 미리보기 복원

v2.3.0에서 탭바 드래그 멈춤 버그를 고치며 HTML5 네이티브 드래그를 없앴는데, 그 부작용으로
브라우저가 자동으로 그려주던 "마우스에 탭이 붙어서 따라다니는" 미리보기도 같이 사라졌습니다.
별도의 작은 always-on-top 창으로 다시 만들어 복원했습니다 — 화면 좌표 기준이라 창 밖으로
드래그해도(새 창으로 분리하려는 제스처) 계속 보이고, 클릭은 항상 통과시켜 실제 드래그 판정에는
관여하지 않습니다. 그림자가 잘리지 않게 여백을 두고, 살짝 들어올려지는 느낌과 활성 탭 색상을
반영한 강조 바도 추가했습니다.

## 검색 닫아도 하이라이트가 다시 나타나던 버그 수정

터미널에서 문자열 검색 후 검색창을 닫아도, 그 뒤 터미널에 새 출력이 들어오면 지웠던 하이라이트가
다시 칠해지는 문제가 있었습니다. 검색을 닫을 때 하이라이트 재적용 구독까지 확실히 해제하도록
고쳤습니다.

## 그 외

- 파일전송 연결 해제/터미널 워커 종료 시 불필요하게 반복 출력되던 디버그 로그 제거
- 배포 채널 정리: 이번 버전부터 설치 파일 배포는 `pepe-terminal-ssh-pub`(공개) 저장소를
  통해 이뤄집니다. 자동 업데이트 확인 경로도 함께 옮겨졌습니다.
