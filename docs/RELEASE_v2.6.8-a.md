# v2.6.8-a

2.6.8 의 **보조판**입니다. SSH 세션이 멋대로 끊기던 문제를 잡고, AI Chat 의 대화 탭 수를
직접 고를 수 있게 했습니다.

## 🔌 탭 하나를 닫았는데 다른 세션이 끊기던 문제

터미널 탭을 닫거나 세션을 연결 해제하면, **상관없는 다른 서버 세션이 같이 끊겼습니다.**

```
SSH 오류: 터미널 워커가 예기치 않게 종료됐습니다 (code=1)
원격 호스트 연결 끊김
```

자동 재접속이 바로 붙어서 작업이 날아가지는 않았지만, 쓰다 보면 "요즘 연결이 자꾸 끊긴다"로
느껴졌습니다. 네트워크 문제처럼 보였는데 아니었습니다 — 앱이 멀쩡한 세션을 죽이고 있었습니다.

세션들은 워커 스레드를 **나눠 씁니다**(스레드 수는 CPU 코어 수에 묶여 있고 최대 6개입니다).
코어가 12개인 PC라면 세션 7번째부터 1번째와 같은 스레드에 얹힙니다. 그런데 연결 해제 처리가
워커를 **통째로** 끄고 있었습니다 — 세션 하나가 아니라요. 세션마다 워커가 하나씩이던 시절의
코드가 그대로 남아 있던 자리입니다.

이제 닫는 세션 하나만 끝내고, 그 스레드에 아무도 남지 않았을 때만 스레드를 닫습니다.

> 세션을 6개 이하로 쓰셨다면 겪지 않으셨을 문제입니다. 그 아래로는 세션마다 스레드가 따로
> 생겨서 서로 겹치지 않습니다.

## 🗂 AI Chat 대화 탭을 12개까지

AI Chat 에서 동시에 열어둘 수 있는 대화 탭이 **4개**로 묶여 있었습니다. 이제 **옵션 > AI** 에서
**4~12개** 중에 고르실 수 있습니다. 기본값은 **8개**입니다.

4라는 숫자에 뜻이 있었던 게 아닙니다. **격자 보기가 2x2 로 못박혀** 있어서, 다섯 번째 탭은
열어도 화면에 담을 자리가 없었습니다. 그래서 탭 수 자체를 막아 "열었는데 안 보이는" 상황을
피하고 있었습니다.

- **격자 보기가 탭 수를 따라 늘어납니다.** 가로를 먼저 넓히고 그다음 세로로 늘립니다 — 대화는
  폭이 좁으면 읽기 나쁩니다
- 칸 크기는 예전처럼 **전부 똑같이** 나눕니다. 대화가 긴 칸이 더 커지지 않습니다
- **좌우 분할·상하 분할은 그대로 2개**입니다. "둘로 나눈다"는 뜻이니까요

> 상한을 **낮추셔도 지금 열려 있는 탭이 바로 닫히지는 않습니다.** 다음에 AI Chat 을 열 때
> 넘치는 만큼 정리됩니다.

## ℹ️ 버전 번호에 대해

`2.6.8-a` 는 버전 규칙상 **2.6.8 보다 낮은 번호**로 취급됩니다(붙임표 뒤가 붙으면 정식판보다
앞선 판으로 봅니다). 그래서 이 판을 설치하시면 자동 업데이트가 **2.6.8 을 새 버전이라며
권할 수 있습니다.** 내용은 이 판이 더 최신이니 그 안내는 넘기셔도 됩니다.
