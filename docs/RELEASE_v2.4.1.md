# v2.4.1

**앱 안의 모든 탭 바가 같은 방식으로 움직입니다.** 어디서든 가운데 버튼으로 탭을 닫고, 휠로 넘기고,
탭이 많으면 목록에서 골라 갈 수 있습니다. 메신저에는 상대 이름과 상대가 쓰는 버전이 나옵니다.

## 🗂 모든 탭 바 — 조작이 하나로

탭 바마다 되는 것이 달랐습니다. 어떤 곳은 휠이 안 먹고, 어떤 곳은 굵은 가로 스크롤바가 드러나고,
가운데 버튼으로 닫히는 곳도 일부였습니다.

```
[탭][탭][탭][탭] …  ‹ ›  ＋  ▾
```

- **가운데 버튼(휠 클릭)으로 탭 닫기** — 모든 탭 바
- **휠로 좌우 이동** — 세로로 굴리면 탭이 옆으로 넘어갑니다
- **`‹ ›`** — 탭이 넘칠 때만 나타납니다
- **`▾` 모든 탭 보기** — 목록에서 바로 고르고, 목록에서 닫을 수도 있습니다
- **가로 스크롤바 제거** — 탭 자리를 잡아먹던 굵은 바가 사라졌습니다

적용 범위: 워크스페이스 탭바 · 터미널 미니탭 · 파일 패널 · 브라우저 · 오피스(형식) ·
워드/한글/PDF/플로차트/미디어 · Pepe-Box · SQL Tool.

> 오피스 문서 탭이 여러 개일 때 스크롤바만 있고 `‹ ›` 가 없던 것, 파일 패널에서 가운데 버튼이
> 안 먹던 것도 함께 고쳤습니다.

## 🖥 아주 좁은 창에서 파일/문서 목록이 잘리던 문제

메신저 사용자 목록이 창 폭을 조금만 줄이면 **한 명만 보이고 사라졌습니다.** 위아래로 쌓는 배치를
쓰려 했지만 그 규칙이 한 번도 적용되지 않아, 높이만 눌린 상태였습니다. 이제 어떤 폭에서도 왼쪽
세로줄에 전원이 보이고, 좁아지면 아바타만 남기고 자동으로 접힙니다.

**사용자 목록 접기 버튼**이 생겼습니다. 넓은 창에서도 접어서 대화 영역을 넓게 쓸 수 있습니다.

## 💬 메신저

- **상대 이름이 말풍선 위에 나옵니다.** 상대가 이어 보낸 묶음의 맨 위에 한 번만 붙습니다
  (10분 이상 벌어지면 다시 붙습니다). 내 메시지에는 붙지 않습니다
- **상대가 쓰는 PePe 버전이 보입니다** — 목록에서는 주소 뒤에 `v2.4.1`, 대화 머리말에는
  `PePe 2.4.1`. 문제가 생겼을 때 서로 버전을 물어보지 않아도 됩니다
  (2.4.1 이전 버전을 쓰는 상대는 표시가 생략됩니다)
- **알림 창의 "열기"** 가 메신저만 띄우고 예전에 보던 상대가 남아 있었습니다 — 이제 알림이 온
  상대의 대화로 바로 갑니다
- **읽은 표시가 재설치·재기동 후에도 유지됩니다.** 메시지는 남는데 읽은 표시만 사라져서 전부
  안 읽은 것처럼 보였습니다(저장 위치를 설정 파일로 옮겼습니다)
- 이모티콘 고르는 곳의 분류 줄을 **휠로 넘길 수 있습니다**
- 이모티콘 아래 날짜가 `2026.` 부터 잘려 보이던 것을 고쳤습니다
- 접속 중인 상대의 **마지막 발견 시각**이 초 단위로 계속 굴러 눈에 거슬렸습니다 — 10초 단위로
  묶어서 보여줍니다

## 📜 오래 떠나 있던 탭으로 돌아올 때 스크롤이 튀던 문제

로그를 위로 올려 읽다가 다른 곳에 한참 있다가 돌아오면 **화면이 맨 아래로 내려갔다 원래 자리로
돌아왔습니다.** 될 때도 있고 안 될 때도 있어 재현이 까다로웠습니다.

안 보이는 탭은 1분이 지나면 메모리를 아끼려고 화면 내용을 접어두는데, 돌아올 때 그것을 통째로
다시 써 넣습니다. 다 쓰기 전에는 되돌릴 위치 자체가 없어서 어떻게 해도 중간 상태가 보였습니다.
이제 **스크롤을 올려둔 탭은 접어두지 않습니다** — 읽던 중인 화면이라 그대로 두는 것이 맞습니다.
맨 아래를 보고 있던 탭은 예전처럼 접어두므로 메모리 절약은 유지됩니다.

## 🔧 도구모음 — 캡처·개발자 도구 버튼을 골라서 켭니다

평소 쓰지 않는 버튼 두 개가 도구모음 자리를 차지하고 있었습니다. 이제 **기본으로 숨기고**
메뉴 > 도구에서 켭니다. 켜면 옵션(⚙️) 오른쪽에 붙습니다.

```
메뉴 > 도구
  📸 화면 캡처 버튼 표시
  🛠️ 개발자 도구 버튼 표시
```

화면 캡처는 버튼을 숨겨도 **F9** 와 메뉴로 그대로 됩니다.
