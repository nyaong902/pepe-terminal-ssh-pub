# v2.6.0

**화면이 밝아집니다.** 상태바에서 `시스템 / 밝게 / 어둡게` 를 고르면 터미널을 뺀 앱
전체가 따라갑니다. 여기에 인코딩 `자동` 선택과 표 복사가 더해졌습니다.

## 🌗 화면 테마 — 시스템 / 밝게 / 어둡게

여러 개였던 색상 테마를 OS 관례대로 셋으로 줄였습니다. 상태바 오른쪽 끝에서 바로 바꿉니다.

- **시스템** — Windows 설정을 따라갑니다. OS 에서 밝게/어둡게를 바꾸면 **앱을 다시 켜지
  않아도** 즉시 따라갑니다
- **밝게** — 흰 바탕. 글자·테두리·강조색을 밝은 바탕에 맞게 다시 잡았습니다
- **어둡게** — 지금까지의 그 색 그대로입니다

처음 설치하면 **어둡게(기본)** 입니다. 업데이트만으로 화면이 갑자기 밝아지지 않습니다.

### 예전 색상 테마도 그대로 있습니다

Cyber Blue, Deep Teal, Emerald, Royal Purple, Wine, Sunset, Coffee — 없어진 게 아니라
**어둡게의 하위 선택**으로 들어갔습니다. `어둡게(기본)` 옆 화살표(▴)를 누르면 목록이 뜹니다.
지금 무엇을 쓰고 있는지는 괄호 안에 나옵니다(`어둡게(Cyber Blue)`).

### 밝게는 어디까지 적용되나

AI Chat(코드 색칠·mermaid 다이어그램 포함), DB SQL 도구의 쿼리 편집기와 결과 표,
파일 비교, 파일 탐색기, 메신저, 작업일지, SSW CDR 로그분석까지 들어갑니다.

**터미널 화면은 바뀌지 않습니다.** 터미널은 예전부터 자체 테마 설정을 따로 갖고 있고,
그쪽을 쓰시던 설정을 덮어쓰지 않기 위해 그대로 두었습니다.

## 🔤 인코딩 — `자동 (시스템 기본)`

세 곳(빠른 연결 · 세션 편집 · 터미널 우클릭)이 각자 다른 목록을 들고 있었습니다. 개수도
이름도 달라서(`latin1` / `iso-8859-1`) 어느 쪽에서 고르느냐에 따라 저장되는 값이
달랐습니다. **하나로 합쳤습니다.**

이름도 코드만 늘어놓지 않고 쓰는 언어를 붙였습니다:

```
자동 (시스템 기본)   유니코드 (UTF-8)     한국어 (CP949)
한국어 (EUC-KR)      일본어 (Shift-JIS)   중국어 간체 (GBK)
중국어 번체 (Big5)   서유럽 (Latin-1)
```

`euc-kr` 과 `cp949` 중 무엇을 골라야 하는지는 코드만 봐서는 알 수 없었습니다.

### '자동' 은 이렇게 동작합니다

**UTF-8 로 읽다가, UTF-8 이 아니면 그때 시스템 코드페이지로 넘어갑니다.**

접속하자마자 OS 언어로 정해 버리면 한국어 PC 에서 UTF-8 서버에 붙을 때 전부 깨지고,
UTF-8 로 고정하면 옛 서버에서 깨집니다. UTF-8 은 스스로 검증되는 형식이라 "이 바이트는
UTF-8 이 아니다" 를 확실히 알 수 있어서, 그 순간에만 한 번 넘어갑니다.

새로 만드는 연결은 **기본이 자동**입니다. 이미 저장된 세션은 건드리지 않습니다.

파일 전송 목록에서는 **이름마다 따로** 판단합니다 — 한 폴더에 UTF-8 이름과 옛 코드페이지
이름이 섞여 있는 경우가 흔해서, 폴더 단위로 하나를 고르면 어느 쪽이든 깨집니다.

## 📋 AI Chat — 표를 표 모양 그대로 복사

표를 끌어 고르면 칸 내용이 구분 없이 붙어 나와 알아볼 수 없었습니다. 표에 마우스를
올리면 **`표 복사 ▾`** 가 뜹니다.

| 고르는 것 | 쓰는 곳 |
|---|---|
| 📝 마크다운 | 문서·이슈 — 붙이면 다시 표로 그려집니다 |
| 🔠 ASCII 표 | 터미널·메일처럼 그대로 보는 곳 |
| 🖼 그림 (PNG) | 메신저·슬라이드에 바로 붙여넣기 |
| 💾 그림으로 저장 | 파일로 떨어뜨리기 |

끌어서 `Ctrl+C` 한 경우도, 범위가 한 표 안에 들어 있으면 표 모양을 유지합니다.

ASCII 표는 한글·한자가 고정폭에서 두 칸을 차지하는 것까지 계산하므로 테두리가 어긋나지
않습니다.

### 코드·다이어그램을 긁으면 버튼 글자가 딸려오던 문제

`코드 복사`·`내보내기` 버튼은 코드 블록과 그림 **위에 겹쳐** 있어서, 세로로 긁으면 반드시
지나가고 그 글자까지 복사됐습니다. 선택에서 뺐습니다.

### 입력 히스토리

입력창에서 `↑` 를 누르면 왼쪽 위에 **`히스토리 3/12`** 가 뜹니다. 몇 번째인지 보이지
않으면 끝까지 왔는지 알 수 없어 같은 키를 계속 누르게 됐습니다.

보관 개수도 10개에서 **100개**로 늘렸습니다. 대신 4,000자가 넘는 긴 입력은 히스토리에
넣지 않습니다 — 그런 내용은 대화에 이미 남아 있고, 방향키로 꺼내 쓰는 건 짧은 명령입니다.

## 🔧 그 밖에

- **pcap 더블클릭** — 파일 트리에서 pcap 을 더블클릭하면 미디어/로그분석 중 어느 것으로
  열지 묻지 않고 일반 문서로 열리던 문제를 고쳤습니다
- **음원 편집** — 실행 취소와 원본으로 되돌리기 버튼이 생겼습니다
- **로컬 셸 인코딩 메뉴** — PowerShell 등 로컬 셸에서는 우클릭 `인코딩 변경` 이 아무 일도
  하지 않았습니다(바이트를 해석하는 단계가 없습니다). 동작하지 않는 항목이라 감췄습니다
- **AI Chat 로그인 만료** — 로그인 세션이 만료되면 사용량 조회가 원문 401 을 그대로
  뱉었습니다. 무엇을 해야 하는지 안내하도록 고쳤습니다
- **"파일을 놓으면 첨부됩니다"** 표시가 드래그를 끝내도 사라지지 않던 문제를 고쳤습니다
