# v2.5.9

**AI Chat 이 통째로 다시 만들어졌습니다.** 이제 어느 AI 를 쓰든 대화를 여러 개 띄우고
나란히 놓고 쓸 수 있습니다. 여기에 Mantis CR 조회, 작업일지 자동 등록, PDF 읽기가
더해졌습니다.

## 💬 AI Chat — 모든 AI 에서 멀티탭과 분할 보기

예전에는 대화를 여러 개 띄우는 기능이 `claude+` 라는 별도 항목에만 있었습니다. 그
구분을 없애고 **claude / gemini / codex / copilot / antigravity / OmniRoute / Custom LLM
전부**에 같은 기능을 넣었습니다.

- **미니탭** — 열어둔 대화가 위쪽에 탭으로 늘어섭니다. 가운데 클릭으로 닫고,
  우클릭으로 이름을 바꿉니다. 각 탭에 어떤 AI 인지 아이콘이 붙습니다
- **분할 보기** — 두 대화를 나란히 놓고 비교하며 쓸 수 있습니다
- **대화마다 독립된 설정** — SSH 접속 대상, 마운트한 폴더, 모델, 사고 수준(effort),
  권한 모드가 **대화별로** 기억됩니다. 다른 대화로 옮겨도 그 대화의 설정이 그대로 살아납니다

`claude+` 를 쓰시던 분들은 따로 하실 일이 없습니다 — 기존 대화는 그대로 `claude` 로
이어집니다.

### 대화 제목을 알아서 지어줍니다

첫 질문과 답변이 끝나면 **짧은 제목이 자동으로 붙습니다.** 예전에는 첫 문장 앞부분이
그대로 잘려 들어가 목록에서 구분이 어려웠습니다.

직접 지은 이름, 복제본(`- COPIED`), 포크(`🍴`) 표시는 덮어쓰지 않습니다.

### PDF 를 읽습니다

AI 대화에 PDF 를 붙이면 예전에는 *"PDF 렌더링 도구가 없어서 텍스트 추출을
시도하겠습니다"* 로 끝났습니다. 이제 **각 쪽을 이미지로 렌더해서** 넘깁니다 — 표나
도면이 들어간 문서도 그대로 봅니다. 몇 쪽짜리 문서의 몇 번째 쪽인지도 함께 알려주므로
순서를 잃지 않습니다.

## 🔎 Pepe-Mantis — CR 을 대화 중에 바로 조회

같은 PC 에서 Mantis CR Ultra Hub(E-sim) 가 떠 있으면, 그 화면을 **워크스페이스 탭으로
바로 열 수 있습니다**(커맨드 팔레트 / 도구 메뉴 / 탭 + 드롭다운 세 곳에 진입점).

여기에 더해 **AI 가 CR 을 직접 조회**합니다. 대화 중에 CR 번호를 말하면 AI 가 찾아서
읽습니다. `16126` 처럼 숫자만 줘도 되고 `crdb00016126` 같은 형식도 받습니다.
SSH 에 접속하지 않은 로컬 대화에서도 동작합니다.

서버 주소는 옵션에서 바꿀 수 있습니다(기본값 localhost).

구체적인 to-do 여러 개로 쪼개서** 오늘 날짜 작업일지에 등록합니다. 모든 AI 에서
동작합니다.

## 🔐 인증이 언제 끝나는지 보입니다

로그인이 조용히 만료되면 갑자기 안 되는 것처럼 보였습니다. 이제 🔑 버튼에 마우스를
올리거나 API 키 설정을 열면 **남은 기간**이 보입니다.

```
로그인 세션: 8시간 0분 남음
갱신 기한: 21일 14시간 남음 — 이때까지는 재로그인 없이 자동 갱신
```

1년 장기 토큰(`claude setup-token`)을 쓰시는 경우도 함께 표시됩니다.

> 참고 — 사용량 조회는 **일반 로그인 세션**이 필요합니다. 1년 장기 토큰에는 그 권한이
> 없어(추론 전용) 사용량만 표시되지 않습니다. 대화는 장기 토큰으로 정상 동작합니다.

## 📊 다이어그램(mermaid) 안정화

AI 가 그려주는 도표가 깨지던 경우들을 고쳤습니다.

- **라벨이 여러 줄에 걸친 경우** — 코드 블록이 중간에 끊겨 뒷부분이 글자로 새어나오고,
  그림은 안 그려졌습니다. 2줄이든 5줄이든 제대로 읽습니다
- **라벨에 `/` `--` `<br/>` 이 든 경우** — 살균 과정이 라벨 안의 글자를 화살표 문법으로
  오인해 문장을 부수고 있었습니다
- **원통(DB) 모양이 사각형으로 뭉개지던 문제**
- **앱을 막 켰을 때** 이미 그려진 그림이 ASCII 로 강제 변환되며 깨지던 문제
- ASCII 로 떨어진 도표가 **다시 그림으로 돌아오지 않던 문제**

## ⌨ 붙여넣기의 공백이 `?` 로 들어가던 문제

AI 대화에서 코드를 복사해 터미널에 붙여넣으면 **공백 자리마다 `?`** 가 찍혔습니다.

```
else?if?(strstr?(next,?REL_PREFIX))
```

복사한 글에 섞여 있던 특수 공백(겉보기엔 스페이스와 똑같지만 다른 문자) 때문이었습니다.
세션 인코딩(EUC-KR 등)에 없는 문자라 `?` 로 바뀌어 전달됐습니다.

이제 터미널로 보내기 직전에 정리합니다 — **SSH · Telnet · 로컬 셸 모두** 적용되고,
AI 대화뿐 아니라 브라우저나 문서에서 복사한 글을 붙여넣을 때도 같이 해결됩니다.
보이지 않는 폭 0 문자(명령만 조용히 망가뜨리던)도 함께 걸러냅니다.

> 한글·일본어 문장에서 쓰는 전각 공백(`　`)은 실제 글자이므로 그대로 보냅니다.
> 이미지 같은 바이너리 붙여넣기도 건드리지 않습니다.

## 🖥 그 밖의 수정

- **세션 이름이 전부 `#1` 로 붙던 문제** — 더블클릭으로 여러 개를 빠르게 열거나
  우클릭으로 복제할 때 번호가 올라가지 않았습니다
- **AI 대화가 사라지던 문제** — 워크스페이스 탭을 닫으면 마지막 대화가 저장되지 않았습니다
- **창 안에서 글자를 드래그해 바깥에서 놓으면 창이 닫히던 문제** — 앱 전체 19곳.
  SSH 비밀번호 입력창도 포함이라, 입력하던 값이 날아갔습니다
- **파일트리 목록이 중간에서 끊기고 아래가 비던 문제** (VPN 로그 목록도 같은 원인)
- **AI 대화 이름변경(✎) 버튼이 먹통이던 문제**
- **짧은 확인 답("응", "네")을 보내면 앞 내용을 잊던 문제**
- **Antigravity 모델 목록** 도 CLI 에게 직접 물어봅니다 — 앱에 적어둔 5개가 전부 없는
  모델이었습니다
- **OmniRoute / Custom LLM 설정이 재설치 후 기본값으로 되돌아가던 문제**
- **codex 로컬 대화에서 `401 Unauthorized` 가 반복되던 문제**
- **작업일지** — 한글 입력 후 엔터를 치면 조합 중이던 글자만 담긴 항목이 하나 더 생기던 문제
- **파일 비교** — 한쪽에만 있는 항목에 "내용 같음" 안내가 잘못 뜨던 문제,
  hunk 병합 화살표가 겹쳐 보이던 문제
- **mac** — 창 컨트롤(신호등)을 좌측 상단에 표시, dmg 창에 숨김 파일이 노출되던 문제
