# v2.2.18

## 자동 업데이트 중 커스텀 페이지 재도전 — 창 강제 표시

v2.2.16에서 커스텀 페이지(사용자 데이터 삭제 확인, 기능 선택)를 자동 업데이트 중에도 보여줬더니 설치 창이 다시 안 뜨는 문제가 재현돼 v2.2.17에서 되돌렸습니다. 이번엔 페이지를 다시 보여주되, 원인으로 의심되는 지점을 보강했습니다.

`BringToFront`는 이미 보이는 창을 앞으로 가져올 뿐인데, 자동 업데이트 흐름에서는 이 페이지들이 건너뛰지 않는 첫 화면이라(그 전 페이지들은 다 건너뛰므로) 창이 아직 한 번도 안 보인 상태일 수 있습니다. Windows API를 직접 호출해 창을 명시적으로 `SW_SHOWNORMAL`로 띄우고 `SetForegroundWindow`로 강제 포그라운드까지 시도하도록 두 페이지 모두에 추가했습니다.

이번에도 재현되면 v2.2.17의 "자동 업데이트 시 건너뛰기"로 다시 돌아갈 예정입니다.
