# v2.2.5

## 자동 업데이트 진단 로그 추가

일부 PC에서 앱 내 자동 업데이트 후 "재시작하여 설치"를 눌러도 설치 창이 전혀 뜨지 않는 문제가 계속 보고되고 있습니다. v2.2.1/v2.2.3에서 각각 다른 원인(페이지 표시 방식, 권한 상승 방식)으로 추정해 수정했지만 현장에서 재현되지 않아 효과를 확인하지 못했습니다 — 특히 v2.2.3(설치 페이지를 보이게 한 버전)으로도 여전히 설치 창과 페이지 모두 안 뜨는 게 확인되어, 페이지 표시 여부와 무관한 더 근본적인 문제로 보입니다.

더 이상 추정으로 고치지 않고, 실제 로그를 확보해서 원인을 확정하기 위해 진단 로그를 추가했습니다.

- `%APPDATA%\PePe Terminal(SSH)\update-debug.log` 에 자동 업데이트 전 과정(확인/다운로드/"재시작하여 설치" 클릭/`quitAndInstall` 호출 및 예외/electron-updater 에러)을 타임스탬프와 함께 기록
- 지금까지는 패키지 빌드에서 콘솔 로그가 꺼져 있어 이 정보가 어디에도 안 남고 있었음

**중요**: 이 로그는 "현재 실행 중인 앱"이 기록합니다. 문제가 나는 PC가 지금 이 버전보다 낮은 버전을 쓰고 있다면, 자동 업데이트로 이 버전까지 끌어올리는 과정 자체가 막혀 있을 수 있으므로, **이 버전(v2.2.5)을 해당 PC에 먼저 수동으로 설치**해두어야 합니다. 그 상태에서 이후 버전으로 자동 업데이트를 다시 시도했을 때 남는 로그를 확보하면 정확한 원인을 알 수 있습니다.
