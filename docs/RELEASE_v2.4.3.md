# v2.4.3

**손에 걸리던 것들을 걷어낸 판입니다.** 작업표시줄에 고정해 둔 아이콘에서 바로 열리고, 글꼴 크기가
껐다 켜도 유지되고, 빠른 연결 바를 더블클릭해도 창이 멋대로 커지지 않습니다. 도구 메뉴도 정리했습니다.

## 📌 작업표시줄에 고정한 아이콘에서 바로 열립니다

고정해 둔 PePe 를 눌렀는데 **오른쪽에 아이콘이 하나 더 생기고 거기에 창이 열렸습니다.**

Windows 는 `AppUserModelId` 라는 값으로 "이 창이 어느 앱인지" 판단합니다. 그 값이 설치본이 만든
바로가기와 실행 중인 앱에서 서로 달라서, Windows 가 둘을 다른 앱으로 본 것입니다. 두 값을 맞췄습니다.

> **설치 후 한 번만**: 작업표시줄의 기존 PePe 고정을 **해제**하고 시작 메뉴에서 **다시 고정**해
> 주세요. Windows 가 이전 값으로 만든 고정 항목을 캐시하고 있습니다.

## 🗂 도구 메뉴 정리

항목이 스무 줄을 넘어 길었습니다. 하위 메뉴로 묶었습니다.

```
도구
 ├ 🗂 워크스페이스 ▸   파일 전송 · 브라우저 · 파일 비교 · 로그 분석 · VPN · Pepe-Box ·
 │                    MicroSIP · SSW 소프트폰 · SIPp · SSW CDR 로그 분석 ·
 │                    다국어 지원 · 대화 아카이브 검색 · Pepe-Thing
 ├ 🖧 PePe 원격 공유
 ├ 📸 화면 캡처 ▸      캡처(F9) · 저장 위치 변경 · 폴더 열기
 ├ 도구 모음 바 숨기기 …
 └ ⊗ X 서버 ▸
```

- 도구모음의 **📸 버튼에도 `▾` 하위 메뉴**가 붙었습니다(X 서버 버튼과 같은 방식) — 저장 위치
  변경을 우클릭으로만 할 수 있어 찾기 어려웠습니다
- 하위 메뉴가 화면 아래쪽에서 잘리던 것도 고쳤습니다(13개 항목이면 361px 이라 잘렸습니다)

## 🔤 글꼴 크기가 유지됩니다

터미널과 AI 챗의 글꼴 크기를 바꿔도 **앱을 껐다 켜면 기본값으로 돌아갔습니다.** 두 설정이 실행마다
비워지는 저장소에만 들어 있었습니다 — 설정 파일에 함께 저장하도록 고쳤습니다.

## ⚡ 빠른 연결 바

- **컨트롤을 더블클릭하면 창이 최대화/복원되던 문제** — SSH/SFTP 선택, IP·Port·ID·PW, 인코딩,
  연결 버튼 모두 해당됐습니다. 바 자체는 타이틀바처럼 동작하게 만든 것인데, 그 판정이 더블클릭에만
  빠져 있었습니다. 행의 빈 공간에서는 예전처럼 창을 옮기고 최대화할 수 있습니다
- **빠른 연결로 붙인 세션이 워크스페이스 목록에 나옵니다** — 저장된 세션이 아니라는 이유로
  SSW CDR 로그 분석·로그 분석·파일 비교·커스텀 워크스페이스의 SSH 선택 목록에서 빠져 있었습니다

## 📁 파일 전송 — 파일 목록 가로 스크롤

컬럼 폭 합이 패널보다 넓으면 오른쪽(권한·소유자)이 **그냥 잘려서 볼 수 없었습니다.** 이제 가로로
스크롤되고, 헤더가 목록과 정확히 함께 움직입니다.

## ⌨ 옵션 — 단어 구분기호

옵션 화면의 단어 구분기호 칸이 **비어 보이고, 그대로 저장하면 값이 지워졌습니다.** 이제 실제 적용 중인
값이 보이고, **기본값으로** 버튼으로 되돌릴 수 있습니다.
