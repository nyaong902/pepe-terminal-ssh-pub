## 2. 세션 관리

### 세션 리스트

![세션 리스트](screenshots/02-session-list.png)

- 세션은 폴더별로 계층 구조로 정리 가능
- 드래그앤드롭으로 폴더 이동
- 우클릭으로 이름 변경/삭제

### 선택 방식

- **단일 클릭**: 세션 선택 (인코딩/설정 바 표시)
- **더블 클릭**: 현재 선택된 패널에 연결
- **Ctrl + 클릭**: 다중 선택 토글
- **Shift + 클릭**: 범위 선택 (anchor부터 클릭 위치까지)

### 다중 선택 + 일괄 연결

여러 세션을 선택한 뒤 우클릭하면 다음 옵션이 나옵니다:

![다중 선택 컨텍스트 메뉴](screenshots/03-multi-select-ctx.png)

- **📑 미니탭으로 연결** — 한 패널 안에 탭 형태로 모두 추가
- **▐ 세로 분할로 연결** — 좌우 2분할 (여러 개면 N-열)
- **▄ 가로 분할로 연결** — 위아래 2분할 (여러 개면 N-행)
- **⊞ 타일 분할로 연결** — 자동 그리드 배치
  - N=2 → 1×2, N=3 → 2행(위2/아래1), N=4 → 2×2, N=6 → 2×3, N=9 → 3×3

## 3. 세션 편집기

![세션 편집기 — 기본](screenshots/04-session-editor-basic.png)

### 기본 필드

| 필드 | 설명 |
|---|---|
| **이름** | 세션 표시 이름 |
| **호스트** | IP 또는 도메인 |
| **포트** | 기본 22 |
| **사용자** | SSH 로그인 계정 |
| **인증** | 비밀번호 / 키 파일 |
| **인코딩** | utf-8 / cp949 / euc-kr 등 |
| **폴더** | 세션 리스트에서의 분류 |
| **파일 트리 초기 경로** | `Ctrl+Shift+E` 로 열었을 때 기본 표시 경로 (비우면 홈) |

### 점프 호스트 (ProxyJump) — v2.0.2+

![세션 편집기 — 점프 호스트](screenshots/05-session-editor-jump.png)

bastion 서버 뒤에 있는 내부 서버에 접근하려면 점프 타겟 설정:

| 필드 | 설명 |
|---|---|
| **점프 타겟 호스트** | 최종 연결할 내부 서버 (예: `I-MPM01`) |
| **점프 타겟 사용자** | 예: `root` |
| **점프 타겟 포트** | 기본 22 |
| **점프 타겟 비밀번호** | (선택) 비우면 primary 의 `~/.ssh/id_rsa` 자동 사용 |

**동작 방식**: 앱 → primary 호스트(bastion) → TCP 터널 → 점프 타겟에 직접 SSH + SFTP. 터미널·파일트리 모두 점프 타겟 기준으로 동작.

**Solaris 같은 구형 sshd** 도 레거시 알고리즘(`diffie-hellman-group1-sha1`, `ssh-dss` 등) 자동 협상.

### 로그인 스크립트 (Expect/Send)

![세션 편집기 — 로그인 스크립트](screenshots/06-session-editor-login-script.png)

접속 직후 자동 입력할 스크립트 (예: 2단계 인증 통과, 자동 alias 실행):
- **Expect**: 화면에서 기다릴 문자열 (정규식 지원)
- **Send**: 매칭 시 전송할 문자열

<a id="sec-split"></a>
## 5. 분할 화면 / 워크스페이스

### 워크스페이스 탭

상단 탭바에서 **+** 로 새 워크스페이스 추가. 각 워크스페이스는 독립적인 분할 레이아웃을 가지며, **워크스페이스 간 이동 시 분할 크기가 보존됩니다** (v2.0.10+).

탭 이름은 더블클릭으로 변경, 가운데 클릭으로 닫기 가능.

### 분할 실행

- **패널 헤더의 ▐ / ▭ 버튼**
- **단축키**: `Ctrl+Shift+→` (세로), `Ctrl+Shift+↓` (가로) 등 (단축키 섹션 참고)
- **창 메뉴**: 메뉴바의 "창 → 세로 분할 / 가로 분할"

### 세션 선택 팝업

분할 버튼/단축키 누르면 **현재 활성 세션의 폴더 내 모든 세션** 리스트가 뜹니다:

![분할 세션 선택](screenshots/09-split-session-picker.png)

선택 시 새 터미널이 그 세션으로 연결되며 분할 패널로 배치됩니다. 취소 시 빈 분할.

### 분할 리사이즈

분할 경계선을 마우스로 드래그하여 크기 조절.

### 특수 워크스페이스 — v2.1.0+

상위 메뉴 **도구** 또는 탭바 `＋` 에서 특수 목적 워크스페이스 추가 가능. 각 워크스페이스는 ErrorBoundary 로 격리되어 한 컴포넌트 크래시가 전체 앱을 중단시키지 않습니다.

| 메뉴 | 설명 |
|---|---|
| **🌐 브라우저 워크스페이스** | Electron `<webview>` 로 외부 사이트 렌더. 주소창·뒤로/앞으로·새로고침·줌(0.25 ~ 5.0). google.com 리다이렉트 무한 새로고침 버그 해결됨 (v2.1.1). |
| **🔍 파일 비교 워크스페이스** | 두 디렉토리(로컬↔SFTP) 재귀 walk 후 차이점 트리 표시. EOL·인코딩 배지, 헤더 정렬·필터, 줄 diff 펼침. 50,000 entry 상한. |
| **📈 로그 분석 워크스페이스** | SSH 세션의 로그 파일을 수집·필터·CSV 내보내기. |
| **🔒 VPN 워크스페이스** | OpenVPN 자격증명 관리 + 연결/해제. macOS Universal Binary 번들. |
| **🌍 다국어 편집 워크스페이스** | i18n 번역 키 인라인 편집. 사용자 추가 언어는 `userData/i18n/<lang>/<ns>.json` 에 오버라이드. 헤더에서 현재 UI 언어 변경 가능. |

상단 우측 테마 셀렉터 왼쪽에 **언어 드롭다운**(v2.1.2+) — 워크스페이스 진입 없이도 UI 언어 즉시 전환.

## 8. 파일 트리 (Ctrl+Shift+E)

### 열기 / 토글

![파일 트리](screenshots/12-file-tree.png)

단축키 **`Ctrl+Shift+E`** 로 현재 활성 터미널의 원격 파일 트리를 패널 내부 좌측에 표시/숨김.

OSC 7 기반으로 **현재 디렉토리 자동 추적** — 터미널에서 `cd`하면 파일트리 기준 경로도 따라갑니다.

### 경로바

![경로바](screenshots/13-file-tree-pathbar.png)

| 버튼 | 기능 |
|---|---|
| 경로 입력 + Enter | 지정 경로로 이동 |
| **↵** | 입력창 내용으로 이동 |
| **⬆** | **현재 경로에 파일 업로드** (다중선택 가능) — v2.0.3 |
| **⟳** | 현재 경로 새로고침 (stale 방지) |

### 파일/폴더 클릭 동작 — v2.0.3+

- **파일 단일 클릭**: 선택(파란 강조). 에디터 오픈 안 됨.
- **파일 더블 클릭**: 에디터에서 파일 열기
- **폴더 단일 클릭**: 확장/축소 토글
- **Ctrl + 클릭**: 다중 선택 토글
- **Shift + 클릭**: 범위 선택

- **💾 여러 파일 다운로드 (N개)** — 폴더 한 번 지정 → 모두 그곳에 저장
- **🗑 여러 파일 삭제 (N개)** — 확인 대화상자 후 순차 삭제
- **❎ 선택 해제**

## 10. 파일 전송 탭

### 탭 생성

![파일 전송 탭](screenshots/18-file-transfer-tab.png)

두 가지 방법:

1. **세션 리스트에서 우클릭 → 📁 파일 전송**
2. **탭 바의 + → 📁 파일 전송 워크스페이스**

### 2패널 구조

- 진행률 표시 + 완료 후 자동 새로고침

- **워크스페이스 단위 캐시 60초 TTL** (v2.1.2+) — 연속된 드래그/드롭(매번 새 transferId 생성됨)에도 결정이 기억됨. 60초 비활동 후 새 전송은 다시 묻습니다.

### SSH 자격증명 다이얼로그 — v2.1.1+

저장된 비밀번호가 없는 세션의 SFTP 직접 연결 또는 점프 타겟 연결 시 표시. 사용자명/비밀번호/키 입력. 터미널 포커스 스틸을 차단(focus trap) 하여 입력 도중 키가 다른 패널로 가지 않음. 비밀번호 표시/숨기기 토글 제공.

## 13. ProxyJump (점프 호스트)

![점프 호스트 구조](screenshots/24-proxyjump-diagram.png)

### 언제 필요한가

bastion / jump host 뒤에 있는 내부 서버에 접근할 때. 예:
- 사용자 PC → **EMS (bastion)** → **MPM01 (내부)**
- 사용자 PC → **공인 서버** → **사설망 내부 서버**

### 설정 방법

세션 편집기의 **점프 타겟** 필드에 내부 서버 정보 입력 (섹션 3 참고).

### 동작 세부

1. primary (EMS) 로 일반 SSH 연결
2. primary 위에 `forwardOut` TCP 터널 생성 → 점프 타겟 22번
3. 터널 위에서 **두 번째 SSH 핸드셰이크** (점프 타겟에 직접)
4. 이후 **터미널·SFTP·파일전송·파일트리 모두 점프 타겟 기준**
5. 인증은 (1) 비밀번호 입력 시 사용, (2) 비었으면 primary 의 `~/.ssh/id_rsa` 를 자동 SFTP 로 읽어 재사용 → 기존 passwordless 설정 그대로 활용

### Solaris 등 레거시 서버

`diffie-hellman-group1-sha1`, `ssh-dss`, `3des-cbc` 같은 구형 알고리즘까지 자동 협상.

### 동시 다수 접속

- **500ms stagger** 로 bastion 의 `MaxStartups` drop 방지
- **20s watchdog + 3회 자동 재시도** — 일시적 실패 자동 복구
- Solaris 는 KEX 연산이 느려 7~8초 소요될 수 있음 (정상)

## 16. Media 워크스페이스

오디오/비디오 파일과 통화 녹취 pcap을 재생·편집하는 전용 워크스페이스입니다. 상위 메뉴 **도구** 또는 탭바 `＋`에서 **🎵 Media 워크스페이스**로 추가합니다. 다른 특수 워크스페이스와 마찬가지로 ErrorBoundary로 격리되어 있어 재생/디코딩 중 문제가 생겨도 앱 전체에는 영향을 주지 않습니다.

### 지원 포맷/코덱

| 구분 | 코덱 | 재생 경로 |
|---|---|---|
| 로컬 디코딩 | WAV, A-law, u-law, RAW PCM | 메인 프로세스가 16bit PCM으로 직접 디코딩 → Web Audio API로 재생 |
| GStreamer 사이드카 | AMR-NB, AMR-WB, EVS, OPUS | 네이티브 GStreamer가 WAV로 변환 → 같은 Web Audio 경로로 재생 |
| 영상 | mp4, m4v, mov, webm, ogv | Chromium 내장 디코더로 재생(mkv/avi는 컨테이너 미지원으로 제외) |

파일을 열면 매직 헤더/확장자로 코덱을 자동 판별합니다.

### 파일 열기

- **탭 바의 ＋** 또는 문서가 없을 때 표시되는 **"파일 열기"** 버튼 — 파일 선택 다이얼로그로 오디오/비디오/pcap 파일을 엽니다.
- **외부(Windows 탐색기 등)에서 드래그앤드롭** — 미디어 재생 가능한 확장자(wav/alaw/ulaw/amr/awb/evs/opus/mp4/mov/webm/pcap 등)의 파일만 이 워크스페이스가 반응하고, 그 외 파일(문서/이미지 등)은 다른 워크스페이스가 처리하도록 넘깁니다.
  - **파일 1개만 드롭** — 즉시 열어 자동 재생 준비 상태로 만듭니다.
  - **파일 2개 이상을 한 번에 드롭** — 여러 파일을 한 번에 끌어다 놓아도 마지막 파일만 재생되던 문제를 개선해, 지금은 짧은 시간(150ms) 안에 도착한 파일들을 모아서 2개 이상이면 전부 **최근 문서 목록에만 등록**하고 자동으로 열지 않습니다. 원하는 파일을 최근 문서 목록에서 직접 선택해서 여는 방식으로 동작합니다.

### 최근 문서 / 재생리스트 패널

문서를 하나도 열지 않은 초기 화면 왼쪽에 **최근 문서(위)**와 **재생리스트(아래)** 두 패널이 위아래로 나뉘어 표시됩니다.

**최근 문서**
- 최근에 연 파일이 최신순으로 표시되며, 검색창으로 이름/경로 필터링 가능
- **클릭** — 해당 파일 열기 / **Ctrl+클릭** — 다중 선택 토글 / **Shift+클릭** — 범위 선택
- **우클릭** — "🎶 재생리스트에 추가" 메뉴. 선택된 항목이 있으면 그 전체를, 없으면 우클릭한 항목 하나만 추가
- **×** — 최근 문서에서 제거
- pcap/pcapng 파일은 📡 아이콘으로 표시되며, 코덱이 아직 확정되지 않은 원본이라 재생리스트에는 추가되지 않습니다

**재생리스트**
- 최근 문서에서 우클릭으로 추가한 곡들의 목록 — 순서 자체가 연속재생 순서
- **드래그앤드롭**으로 순서 변경 가능, **클릭**으로 해당 곡 재생, **×**로 제거
- 재생리스트에서 연 곡이 끝까지 재생되면(직접 멈춘 게 아니라 자연 종료된 경우) **다음 곡이 자동으로 이어서 재생**됩니다. 재생 화면 우측에 재생리스트 전체가 표시되어 몇 번째 곡인지, 다음 곡이 무엇인지 확인할 수 있습니다.

### pcap/pcapng 파일 재생 (RTP 스트림 추출)

`.pcap`/`.pcapng`/`.cap` 파일을 열면 그 안에서 발견된 **RTP 스트림 목록**을 보여주는 선택 창(Wireshark의 Telephony → RTP Streams 창과 비슷한 역할)이 뜹니다.

- 목록에는 발신/수신 IP:포트, SSRC, 페이로드 타입(PT), 코덱, 패킷 수, 길이가 표시됩니다.
- 정적 페이로드 타입(u-law/A-law 등)은 코덱이 자동 인식되지만, 동적 페이로드 타입(AMR/EVS/OPUS 등)은 SDP 정보가 없는 pcap만으로 코덱을 확정할 수 없어(Wireshark도 동일한 한계) 드롭다운에서 코덱을 직접 선택해야 합니다. 페이로드 크기로 추정한 코덱이 기본값으로 미리 선택되어 있습니다.
- 코덱을 **EVS**로 선택하면 RTP 페이로드 형식(**header-full** / **compact**)도 추가로 선택합니다. 이 값도 자동 추정되어 기본 선택되어 있습니다.
- **재생** 버튼을 누르면 선택한 스트림만 재조립해 임시 파일로 만들고, 해당 코덱에 맞는 재생 파이프라인으로 재생합니다.

### pcap 재생 중 WAV로 저장

pcap에서 추출한 RTP 스트림은 원본이 raw 코덱(A-law/u-law 등) 파일이라 다른 프로그램에서 바로 열기 어렵습니다. 재생 화면의 **"💾 WAV로 저장"** 버튼(pcap에서 연 문서에서만 표시)을 누르면, 이미 재생용으로 디코딩된 오디오를 표준 WAV 파일로 저장해 다른 도구에서도 재생·공유할 수 있습니다.

### 편집 기능

재생 화면 상단의 **"✂️ 편집"** 버튼(오디오 코덱 문서에서만 표시, 영상 제외)을 누르면 파형 기반 편집 패널로 전환됩니다.

- **파형 표시** — 클릭으로 재생 위치 이동(seek), 드래그로 구간 선택
- **✂️ 선택 구간만 남기기** / **🗑 선택 구간 삭제** — 선택 구간 기준 자르기
- **📈 페이드 인** / **📉 페이드 아웃** — 선택 구간에 페이드 효과 적용
- **🔊 +3dB** / **🔉 -3dB** — 게인 조절(구간 선택 시 그 구간만, 없으면 전체)
- **💾 WAV로 저장** — 편집 결과를 표준 WAV 파일로 저장
- **🎛 모든 코덱 저장** — 편집된 오디오를 원본 코덱을 제외한 나머지 코덱(A-law/u-law/OPUS/EVS/AMR-WB/AMR-NB/WAV 중 6종)으로 한 번에 인코딩해 지정한 폴더에 저장하고 성공/실패 개수를 요약으로 표시
- 편집 연산(자르기/삭제/페이드/게인)은 즉시 버퍼에 반영되므로, 원본을 보존하려면 편집 전에 다른 이름으로 미리 저장해 두는 것을 권장합니다

### 암호화 파일(#!ENC) 재생 / 암호화 코덱 저장

사내 UEnc 포맷(`#!ENC` 헤더 + AES-256-CBC 암호문)으로 암호화된 음원 파일을 지원합니다.

- `#!ENC`로 시작하는 파일을 열면 자동으로 **비밀번호 입력 프롬프트**가 표시됩니다. 비밀번호가 맞으면 내부 코덱을 판별해 바로 재생하고, 틀리면 오류 메시지와 함께 다시 입력할 수 있습니다.
- 편집 패널의 **"🔒 암호화 코덱 저장"** 버튼 — 비밀번호와 `#!ENC` 버전(01~99)을 입력받아, 편집된 오디오를 모든 코덱으로 변환한 뒤 각각 암호화해 저장합니다.
- **사내 전용 설치가 필요함** — 이 암복호화 기능은 회사 시스템키가 있어야 동작하며, 시스템키는 공개 git 저장소에 포함되지 않고 사내에서 별도 배포되는 **crypto-local-package**의 **install-crypto-local.bat**을 실행해야 활성화됩니다. 미설치 상태에서는 "🔒 암호화 코덱 저장" 버튼이 비활성화되고, `#!ENC` 파일을 열어도 복호화가 실패하며 안내 메시지가 표시됩니다.

### EVS/AMR 등 코덱 재생을 위한 GStreamer 사이드카

EVS/AMR-NB/AMR-WB/OPUS 재생은 앱 내장 코드가 아니라 별도의 **네이티브 GStreamer 사이드카**가 파일을 WAV로 변환해준 뒤 재생하는 방식으로 동작합니다. 특히 **EVS 코덱**은 라이선스 제약상 실제 디코더 플러그인을 공개 git 저장소에 포함할 수 없어 더미 placeholder만 커밋되어 있으며, 사내 전용 설치 패키지(evs-local-package 계열)로 실제 플러그인을 별도 설치해야 EVS 파일 재생/저장이 정상 동작합니다. 미설치 상태에서 EVS 파일을 열면 "EVS 코덱은 이 빌드에서 지원되지 않습니다" 안내와 함께 재생이 실패합니다. AMR-NB/AMR-WB/OPUS는 표준 GStreamer 플러그인만으로 동작하므로 이 제약과 무관합니다.

## 17. MicroSIP 워크스페이스

MicroSIP 유사 UI로 여러 대의 SIP 소프트폰(VoIP 단말)을 한 화면에서 동시에 등록·발신·수신 테스트할 수 있는 워크스페이스입니다. 실제 SIP 시그널링/RTP 미디어/코덱(EVS·AMR-WB·AMR·G.711) 처리는 앱에 내장된 네이티브 PJSIP 사이드카(sipd)가 담당하며, 화면은 그 상태를 제어/표시만 합니다.

### 워크스페이스란

- 각 "단말(엔드포인트)" 카드는 물리적인 SIP 전화기 한 대에 대응합니다 — 서버에 등록하고, 번호를 눌러 전화를 걸고, 인입 전화를 받는 등 실제 소프트폰과 동일하게 동작합니다.
- 실제 SIP REGISTER/INVITE 송수신과 RTP 인코딩/디코딩은 화면이 아니라 앱 내부의 네이티브 SIP 데몬(사이드카)이 처리합니다. 화면 우측 상단의 "● SIP 엔진 ON / 미연결" 표시로 사이드카 연결 상태를 확인할 수 있습니다. 엔진이 미연결이면 등록/통화는 실패하지만, 단말 구성을 편집·저장하는 것은 계속 가능합니다.
- 단말은 최대 100대까지 추가할 수 있습니다.

### 단말(엔드포인트) 추가

- 상단 헤더의 **+ 단말 (N/100)** — 새 단말 카드를 추가합니다. 100대에 도달하면 버튼이 비활성화됩니다.
- 새 단말은 서버/사용자 정보가 비어 있는 상태로 생성되며, "설정" 탭에서 값을 채운 뒤 저장해야 등록할 수 있습니다.
- ▲/▼ 버튼으로 목록 순서 변경, 설정 카드 상단의 **설정 복사 ←** 드롭다운으로 다른 단말의 설정(계정 식별 값 제외)을 복사할 수 있습니다.
- 삭제는 설정 카드의 🗑 버튼 — 확인 후 자동으로 등록 해제되며 삭제됩니다.

### 단말 설정 항목

"설정" 탭의 단말 카드는 접이식 섹션으로 구성되며, 값을 바꾼 뒤 **저장** 버튼을 눌러야 반영(재등록)됩니다.

- **📇 계정** — SIP 서버, 도메인, 포트, 전송(UDP/TCP/TLS), 사용자(번호), 인증 ID, 비밀번호, 표시 이름, 아웃바운드 프록시
- **📡 패킷 캡처** — 아래 항목 참조
- **🎚 코덱** — 아래 항목 참조
- **📞 등록·NAT·보안** — 등록 만료(초), 살아유지(초), SRTP(사용 안 함/선택/필수), ICE 사용, 세션 타이머 비활성화, 계정 상태 게시, STUN/TURN 서버
- **⚙ 통화·프로그램** — 발신 prefix, 음성사서함 번호, DTMF 방식(RFC2833/INFO/Inband), 시작 시 자동 등록, 자동 응답, 통화 중 대기, 벨소리 개별 on/off, 자동 녹음, 발신번호 숨김, 방해 금지(DND)

마이크/스피커 장치 선택과 음량 조절은 단말별이 아니라 워크스페이스 상단의 공통(전역) 설정을 사용합니다.

### 등록 / 해제

- 단말 카드 또는 설정 카드의 **등록**/**해제** 버튼으로 개별 제어. 서버/사용자 값이 비어 있으면 버튼이 비활성화됩니다.
- 등록 상태는 색상 점으로 표시됩니다: 등록됨(초록) / 등록 중 / 실패(빨강) / 미등록 / SIP 엔진 미연결.
- 등록 관련 설정을 저장하면 이미 등록된 단말은 자동으로 재등록되어 반영됩니다.
- 헤더의 **전체 등록** / **전체 해제** — 모든 단말을 한 번에 등록/해제.

### 발신 / 수신 / 보류 / 전환 / 뮤트 / DTMF

- 다이얼 패드(1~9, *, 0, #)로 번호 입력, **📞 통화**로 발신(설정된 prefix 자동 적용), **↻ 재다이얼**, **⌫ 지우기** / **C 초기화**.
- 인입 호는 "받기 / 거절" 버튼으로 응답하며, 벨소리(전역+단말별 스위치 모두 켜져 있을 때) 재생.
- 통화 연결 중에는 **⛔ 끊기**, **🎤/🔇 뮤트**, **⏸/▶ 홀드**, **↪ 호전환**, **⏺/⏹ 녹음** 버튼 제공. 통화 중 다이얼 패드는 실시간 DTMF 신호로 전송됩니다.
- 통화 결과(응답/부재중/무응답)와 통화 시간은 "기록(콜로그)" 탭에 자동 기록됩니다.

### 코덱 우선순위

- **🎚 코덱** 섹션에서 사용할 코덱(EVS/AMR-WB/AMR/G.711 A-law/G.711 µ-law)을 체크하고 ▲/▼로 우선순위를 정합니다.
- 코덱을 하나도 선택하지 않으면 발신이 불가능합니다 — 최소 1개, 상대 서버와 호환되는 코덱(대개 G.711)을 포함하세요.

### 뷰 탭 구성

- **☎ 단말** — 단말 카드 + 다이얼 패드 + 콜로그 패널
- **⚙ 설정** — 단말별 상세 설정, 설정 프로비저닝(내보내기/가져오기)
- **⚡ 매크로** — 자동 다이얼링/키 입력 시퀀스 정의·실행
- **👤 주소록** — 연락처 관리 및 프레즌스 표시
- **🗒 기록** — 통화 기록(콜 로그)

### 매크로 기능

**⚡ 매크로** 탭에서 키/홀드(ms)/통화/받기/끊기 스텝을 순서대로 조합해 매크로를 만들고, 대상 단말을 체크한 뒤 **▶ 동시 실행**하면 선택된 모든 단말에서 동시에(반복 횟수만큼) 실행됩니다.

### 단말별 패킷 캡처

각 단말의 실제 SIP/RTP 트래픽을 Wireshark 배포판의 **dumpcap.exe**로 캡처하는 기능입니다.

- 버튼 위치: 전화 탭의 단말 카드, 설정 탭의 단말 설정 카드 모두 **등록/해제 버튼 왼쪽**에 **📡** 아이콘 버튼이 있습니다. 설정 카드 안에는 별도의 **📡 패킷 캡처** 섹션이 있어 캡처 인터페이스를 지정합니다.
- 사용 방법: ① 설정 탭에서 **캡처 인터페이스**를 드롭다운으로 선택(모든 단말이 공유하는 공통 설정) → ② 캡처할 단말의 📡 버튼을 누르면 저장 폴더 대화상자가 뜨고, 폴더를 고르면 즉시 캡처 시작(버튼이 ⏺ 로 바뀌며 빨간색 표시) → ③ 다시 누르면 캡처 중지, 저장 경로가 토스트로 안내됩니다.
- SIP/RTP 트래픽만 필요하므로 내부적으로 UDP만 캡처하도록 필터링되어, 무제한 캡처로 디스크가 가득 차는 것을 방지합니다.
- **사내 전용 설치가 필요할 수 있음** — **capture-local-package**(`install-capture-local.bat`)를 로컬에 설치했거나 시스템에 이미 Wireshark가 설치되어 있으면(기본 경로 자동 인식) 사용할 수 있습니다. 미설치 시 📡 버튼이 비활성화되고 안내 문구가 표시됩니다.

### 일괄 동작 (전체 제어)

**전체 등록** / **전체 해제** / **전체 끊기**(진행 중인 모든 통화 종료) / **전체 뮤트**(하나라도 뮤트 아니면 전체 뮤트, 이미 전체면 해제) / **🔔/🔕 벨소리 전역 스위치**.

### 설정 프로비저닝 (내보내기/가져오기)

- **⬇ 내보내기** — 모든 단말/매크로/주소록 설정을 JSON(`microsip-config.json`)으로 저장. 비밀번호가 평문 포함되므로 취급 주의.
- **⬆ 가져오기** — JSON을 선택해 현재 설정을 덮어씀(확인 대화상자에 단말 수 표시). 100대 초과분은 잘려서 제외되고, 형식이 잘못되면 오류 토스트가 표시됩니다.

<a id="sec-sipp"></a>
## 18. SIPp 워크스페이스

네이티브 SIPp(오픈소스 SIP 부하테스트 도구) 프로세스를 앱 안에서 제어하는 워크스페이스입니다. MicroSIP 워크스페이스가 "상시 켜진 소프트폰"이라면, SIPp 워크스페이스는 "테스트 1회 실행" 모델입니다 — 시작 버튼을 누르면 편집해둔 시나리오로 SIPp 실행 파일이 새로 뜨고, 지정한 CPS(초당 콜 수)만큼 SIP 콜을 계속 만들어내며, 중지하면 프로세스가 완전히 종료됩니다. 통신사망 인터페이스 시험, 스위치/게이트웨이 부하 시험 등에 사용합니다.

### 대상 / 속도

- **대상 호스트/포트**, **로컬 IP/포트(선택)**, **CPS(초당 콜)**(실행 중 값을 바꾸고 적용하면 최대 0.3초 내 반영), **최대 콜 수**(비우면 무제한), **콜 유지 시간(ms)**.
- **고급 옵션** — 최대 동시 콜(`-l`), Call-ID 형식(`-cid_str`), 전송 방식(UDP/TCP/TLS × 소켓 재사용), 각종 타임아웃, 최대 재전송 횟수, UDP 재전송 비활성화, 메시지/에러 로그 저장, Request-URI 사용자명 등. 목록에 없는 sipp 옵션은 **기타 옵션**에 직접 추가 가능.
- 127.0.0.1/localhost가 아닌 실제 장비를 대상으로, 콜 수 1개 초과(또는 무제한)로 시작하면 실수로 대량 발신되는 것을 막기 위해 시작 전 확인 창이 뜹니다.

### 실행 중 제어

- **■ 중지**, **⏸ 일시정지 / ▶ 재개**, **-10 / -1 / +1 / +10**(CPS 즉시 증감).

### 진행 화면 / 통계

실제 SIPp 콘솔과 동일한 **Scenario Screen**(스텝별 진행)과 **Statistics Screen**(종료 후 누적 통계)을 그대로 보여주며, 우측 요약 카드에 생성 콜 수/현재 콜 수/성공·실패/실측 CPS/경과 시간이 실시간 갱신됩니다. 하단 **실행 로그**에서 SIPp 프로세스의 표준 출력/에러를 확인할 수 있습니다.

### 시나리오 구성 — 블록 조립 vs 고급 XML

- **🧩 블록 조립** — SEND(전송)/RECV(응답 대기)/PAUSE(일시정지) 블록을 화면에서 쌓아 흐름을 만드는 모드. 전송 블록은 INVITE/ACK/BYE 등 주요 메서드 + From/To/추가 헤더/바디 포함 여부를 지정하며, 목록에 없는 형태는 **+ 커스텀 메시지**로 원시 SIP 텍스트를 직접 작성합니다. 응답 대기 블록은 기다릴 응답 코드, 선택 여부, rtd/crlf 통계 옵션을 설정합니다. 블록은 **+**로 원하는 위치에 삽입하고 Ctrl+↑/↓로 순서를 바꿀 수 있습니다. **From 도메인 / To 도메인**을 따로 지정해 서로 다른 SIP 도메인 간 통신도 재현할 수 있습니다.
- **고급 XML** — 완전한 SIPp 시나리오 XML을 직접 작성/붙여넣는 모드.
- 두 모드는 **→ 고급 XML로 보내기** / **→ 블록 조립으로 보내기**로 서로 변환 가능합니다.

### 저장된 시나리오

**💾 저장된 시나리오** — 이름을 붙여 저장/새로 저장/불러오기/삭제. 저장된 항목은 블록·XML 구성, 대상 서버 설정, 데이터 파일 내용까지 통째로 보관되어 자주 쓰는 테스트 구성을 재사용할 수 있습니다.

### 데이터 파일 (-inf, 콜마다 다른 번호 주입)

**데이터 파일** 접이식에 CSV(첫 줄은 `SEQUENTIAL`/`RANDOM`/`USER`, 이후 콜 1개당 한 줄, `;` 구분 값)를 입력하면 시나리오에서 `[field0]`, `[field1]`...로 참조해 콜마다 다른 번호 쌍을 주입할 수 있습니다. 데이터 파일에 값이 있으면 새 전송 블록의 From/To 기본값이 자동으로 이 참조를 사용하도록 채워집니다.

### 탭마다 독립 실행

SIPp 워크스페이스 탭 하나마다 완전히 독립된 SIPp 프로세스와 상태를 가지므로, 여러 탭에서 서로 다른 대상으로 동시에 테스트를 돌려도 간섭하지 않습니다.

## 19. 메신저 워크스페이스

같은 사설망(LAN) 안에 있는 다른 PePe Terminal(SSH) 사용자를 UDP 브로드캐스트로 자동 탐색해, 서버 없이(P2P) 바로 텍스트/파일을 주고받는 사내 메신저입니다. 별도 계정 가입이나 중앙 서버 설정 없이, 같은 네트워크 대역에 PePe Terminal(SSH)이 실행 중이면 서로 자동으로 나타납니다.

### 개요 / 동작 방식

- 탐색은 UDP 브로드캐스트+유니캐스트 hello, 실제 메시지·파일 전송은 TCP(임의 포트)로 이뤄집니다.
- 상대는 3초 간격 keepalive로 온라인/오프라인 상태가 갱신되며, 일정 시간 응답이 없으면 자동 오프라인 처리됩니다.
- 왼쪽 사이드바 상단의 점(●)이 자신의 탐색 노출 상태를 나타내며, **프레즌스 숨기기**가 켜지면 회색(숨김)으로 바뀝니다.

### 표시 이름 / 프레즌스 숨기기

- **내 이름** — 상대방 목록에 표시될 이름(비우면 OS 로그인 계정명 사용). 포커스를 벗어나면 자동 저장.
- **프레즌스 숨기기** — 켜면 내 존재를 브로드캐스트하지 않아 다른 사용자에게 안 보이고, 메시지 송신/대역 스캔 등 상대가 나를 인식해야 하는 기능이 모두 비활성화됩니다.

### 피어(사용자) 목록

- 자동 발견된 상대가 나열되며 온라인/오프라인, 안 읽은 메시지 뱃지가 표시됩니다.
- **우클릭 → 사용자 삭제** — 피어 자체와 관련 대화 기록을 함께 삭제(확인 대화상자).
- 대화창 상단의 **대화 삭제** — 피어는 남기고 메시지 기록만 초기화.
- 설정 패널의 **테스트용 더미 사용자 추가** 버튼 — 실제 네트워크에서 상대가 안 잡히는 개발/테스트 환경에서 UI 확인용 온라인 가짜 사용자를 추가합니다(실제로 등록되는 피어가 아니라 화면에만 임시로 보이며, 우클릭 → 삭제로 제거 가능).

### 대화

- 입력창에 입력 후 **Enter**로 전송(Shift+Enter는 줄바꿈). 이모지만으로 구성된 메시지는 말풍선 안에서 크게 표시됩니다.
- 아직 상대가 읽지 않은 내 메시지는 말풍선의 **✕**(보내기 취소)로 회수할 수 있습니다.
- **파일 전송**: 📎 로컬 파일 / 🌐 원격 파일(연결된 세션의 서버 디렉토리 탐색) / 드래그앤드롭 / 붙여넣기(Ctrl+V, 스크린샷 등). 첨부는 입력창 위 목록에 먼저 쌓이고 전송 전 개별/전체 제거가 가능하며, 이미지는 썸네일 미리보기가 함께 표시됩니다. 전송된 파일 메시지는 파일 위치 열기(탐색기)를 지원합니다.
- **업무일지 공유** — 할일을 상대에게 공유하는 전용 메시지 카드. 받는 쪽은 수락/거절 버튼으로 응답하며, 수락하면 오늘 날짜의 내 업무일지에 자동으로 추가됩니다.

### 이모티콘 팝업

입력창 툴바의 🐸 **이모티콘** 버튼으로 팝업을 엽니다.

- **카테고리 탭** — 🕒 최근 사용, 기본 이모지 카테고리(PePe/표정/사람/동물/음식/기호 등), 🎞️ 설치형 GIF 팩.
- 설치된 GIF 팩이 **2개 이상**일 때만 팩 선택 카드가 팝업 상단에 나타나며, 1개뿐이면 자동 선택되어 카드가 표시되지 않습니다. 별도 새로고침 버튼은 없고, 🎞️ 탭 클릭 시 자동으로 최신 설치 상태를 다시 읽어옵니다.
- 이모티콘 그리드의 아이콘 위에 마우스를 올리면 팝업 안쪽 위쪽에 **확대 미리보기**가 떠서, 작은 썸네일만으로 알아보기 어려운 그림을 크게 확인할 수 있습니다.

### 자동 삭제(보관 기간) 설정

**자동 삭제** 체크 + **보관 일수**(기본 30일, 1~3650일)로, 지정 기간보다 오래된 메시지를 주기적으로 자동 정리합니다.

### 팝업 알림 설정

**팝업 알림** on/off, **팝업 스타일**(토스트/가운데), **팝업 유지 시간**(초)을 설정할 수 있습니다.

### 대역 스캔

**스캔** 버튼 — 내 PC가 속한 네트워크 대역과 과거에 알게 된 다른 대역(VPN 등)에 즉시 hello 패킷을 보내, keepalive 주기를 기다리지 않고 같은 네트워크의 다른 사용자를 바로 찾습니다. 진행 상황이 버튼 아래 텍스트로 표시되고 완료 후 자동으로 사라집니다. 프레즌스 숨기기 상태에서는 비활성화됩니다.

### 전체 대화 초기화

**전체 대화 삭제**(위험 버튼) — 확인 후 피어 목록은 유지한 채 모든 대화 기록을 한 번에 삭제합니다.

### 방화벽 규칙 (참고)

설치 시 설치 프로그램이 Windows 방화벽에 **PePe Terminal Messenger**(앱 실행파일 기준 인바운드/아웃바운드 허용, 사설/도메인 프로필)와 **PePe Terminal Messenger ICMP**(ping 진단용) 규칙을 자동 등록합니다. 등록이 실패해도 설치는 계속 진행되며, 이 경우 메신저 첫 실행 시 Windows 자체의 방화벽 허용 팝업에서 수동으로 허용하면 됩니다. 앱 제거 시 두 규칙도 함께 삭제됩니다.

## 20. 오피스 워크스페이스

한글(HWP/HWPX), 워드(DOCX), 엑셀(XLSX), 파워포인트(PPTX), PDF, FlowChart(draw.io) 문서를 앱 안에서 바로 열고 편집하는 워크스페이스입니다. 외부 프로그램을 띄우지 않고, 각 형식 전용 편집기를 앱 리소스에 자체 호스팅해 iframe으로 내장하는 **내장 에디터** 방식입니다.

탭바 **＋**에서 오피스 워크스페이스를 추가하면 형식 선택 화면이 나타납니다. 형식을 고르면 그 이름의 탭이 생성되며, 다시 **＋**를 눌러 다른 형식 탭을 추가로 열 수 있습니다. 각 형식 탭 안에는 문서 단위 미니탭이 따로 있어 문서 여러 개를 동시에 열어둘 수 있습니다.

### 지원 형식과 편집기

| 형식 | 아이콘 | 편집기 | 비고 |
|---|---|---|---|
| 한글(HWP/HWPX) | 📄 | rhwp-studio | 내장 편집기, 실제 편집 가능 |
| 워드(.docx) | 📝 | ZIZIYI Office(ONLYOFFICE 기반) | 내장 편집기 |
| 엑셀(.xlsx) | 📊 | ZIZIYI Office | 내장 편집기 |
| 파워포인트(.pptx) | 📽️ | ZIZIYI Office | 내장 편집기 |
| PDF | 🗎 | pdf.js | 하이라이트/텍스트박스/손글씨/스탬프 주석 편집 가능 |
| FlowChart(.drawio) | 🧩 | draw.io(임베드) | 순서도/다이어그램 편집 |

PDF는 Electron 내장 뷰어를 그대로 쓰면 주석 편집이 불가능(읽기 전용)해, pdf.js를 직접 렌더링 엔진으로 사용해 주석 편집 기능을 구현했습니다.

### 파일 열기

- **📄 새 문서** — 빈 문서를 새 미니탭으로 생성.
- **📂 열기** — 파일 열기 다이얼로그로 로컬 파일을 선택해 새 미니탭으로 엽니다.
- 문서를 하나도 안 열었을 때는 좌측에 **최근 문서** 목록(형식별 최대 100개, 검색 가능)이 나타나 클릭 한 번으로 다시 열 수 있습니다. **×**로 목록에서 제거(파일 자체는 삭제되지 않음).

### 저장

- 한글/워드/엑셀/파워포인트 — 각 편집기 내부의 저장 메뉴 사용.
- PDF — 상단 **저장** 버튼으로 주석까지 포함된 PDF를 저장.
- FlowChart — 상단 **💾 저장** 버튼으로 `.drawio`(또는 `.xml`) 파일로 저장.

### 선택 설치 — 용량이 큰 기능

오피스 워크스페이스(한글/워드/엑셀/파워포인트/FlowChart 편집기 번들)는 설치 용량이 커서(약 220MB), 설치 프로그램의 **컴포넌트 선택** 페이지에서 다른 무거운 기능들(VPN·MicroSIP·SIPp·미디어 재생 코덱)과 함께 켜고 끌 수 있습니다. 체크를 해제하면 해당 편집기 번들이 설치되지 않아 설치 용량/시간을 줄일 수 있으며, 나중에 설치 프로그램을 다시 실행(재설치)해 선택을 바꿀 수 있습니다. PDF 뷰어/편집기는 전용 번들이 없는 순수 JS 기능이라 이 선택 대상이 아니며 항상 사용할 수 있습니다.

## 27. 트러블슈팅

### "Connection lost before handshake" 또는 JavaScript error dialog

v2.0.3 부터 수정됨. 구버전이면 업데이트 권장. 증상 지속 시 DevTools Console(개발 모드) 에 `[ssh-error]` 또는 `[jump-xxxxx]` 로그 확인.

### 동시 다수(13+) Solaris 점프 접속 시 일부 실패

Solaris sshd 의 MaxStartups 또는 KEX CPU 경합. 현재 대응:
- 500ms stagger
- 20초 watchdog + 5초 간격 3회 자동 재시도
- 그래도 실패하면 한 번에 띄우는 세션 수를 줄이거나 간격을 둬서 접속

### "Unsupported algorithm" 에러

Node/OpenSSL 빌드에 해당 암호 알고리즘 바인딩 없음. v2.0.2+ 에서 시스템 가용 알고리즘만 자동 필터하도록 수정.

### 점프 연결 되는데 파일 전송 메뉴에서 다른 서버 파일이 보임

세션 편집 창에서 **점프 타겟 필드가 실제로 저장됐는지** 확인. 세션 저장 후 다시 파일 전송 시도.

### DevTools 열기

개발 모드(`npm run dev`) 에선 자동 오픈. 설치 빌드에선 기본 미노출 (개발자 전용 기능).

- **터미널 패널 클릭 포커스**: 터미널 영역 클릭 시 해당 패널이 활성화되어 파일트리/Claude 컨텍스트가 그 세션으로 전환
- **폴더 펼침/접힘 상태 영속화**: 세션 관리 사이드바의 폴더 접힘 상태가 앱 재시작 후에도 유지 (UIPrefs 저장)

### 개선
- 세션 편집창 최대 높이 `calc(100vh - 80px)` + 내부 스크롤. 타이틀/저장 버튼은 sticky 로 항상 보임
- 파일 트리 패널 오버레이 위치 — 세션 사이드바 pin 상태에 따라 자동 조정 (트리거 바로 옆에서 슬라이드)
- OSC 7 hook 은 세션별 옵션이며, 기본 꺼짐. 주입 명령 노출을 원하지 않는 세션에선 끔.
- 세션 목록 `host:port` 호버 플로팅 툴팁 (목록 공간 절약)
- 세션 편집창 라벨 크기 축소, 입력 필드 최대 너비 제한 (420px)
- Claude 채팅 다중 첨부, 모델 선택, 권한 모드 토글, 슬래시 명령 팔레트 등
- **빠른 연결 바 / 일괄 전송 바**: Esc 로 닫히지 않음 — 입력 도중 실수로 닫히는 문제 방지. 닫으려면 `✕` 버튼만 사용
- **Claude 모든 쉘 세션 공유**: 세션 클릭 시 파일 트리 / Claude 컨텍스트 자동 전환
- **파일 트리 자동 동기화**: OSC 7 hook 옵션 켜진 세션에서 cd 할 때마다 파일 트리가 해당 경로로 자동 이동 (pub/sub 기반, 화면 클릭 불필요)
