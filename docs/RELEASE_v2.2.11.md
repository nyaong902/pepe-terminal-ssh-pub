# v2.2.11

## 자동 업데이트 설치 창 안 뜨는 문제 — 확정 원인 및 수정

v2.2.9/v2.2.10 테스트 로그에서 결정적인 원인이 드러났습니다. `elevate.exe`가 **두 번** 실행되고 있었습니다:

1. 저희가 직접 spawn한 인스턴스 (화면이 보여야 하는 정상 모드)
2. `app.quit()`이 호출되는 순간, electron-updater 자체의 "종료 시 자동 설치" 기능(`autoInstallOnAppQuit`)이 별도로 감지해서 또 한 번 트리거한 인스턴스 — 이번엔 `isSilent: true`, `/S`(완전 무음)로

같은 설치 파일의 두 인스턴스가 거의 동시에 뜨면서, NSIS의 "동시 실행 하나만 허용" 규칙에 의해 둘 중 하나만 살아남는데, 하필 완전 무음 인스턴스가 이겨서 화면 없이 조용히 설치되고 있었습니다. "UAC 승인까지는 뜨는데 그 이후 설치 창이 안 보인다"는 증상과 정확히 일치합니다.

- `autoInstallOnAppQuit`을 꺼서, electron-updater가 종료 시점에 중복으로 설치를 트리거하지 않도록 수정 — 설치 트리거는 이제 "재시작하여 설치" 버튼을 눌렀을 때 저희가 직접 제어하는 경로 하나만 남습니다
