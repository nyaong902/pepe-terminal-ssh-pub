# 터미널 / 세션 관리

PePe Terminal(SSH)의 기본 기능 — SSH/SFTP 다중 세션을 하나의 창에서 관리합니다.

![터미널 기본 화면](../screenshots/terminal-01-basic.png)

## 핵심 기능

- **다중 세션**: 여러 서버에 동시 접속해 탭/미니탭/분할 화면으로 관리
- **분할 화면**: 세로/가로/타일 분할 — 여러 서버 화면을 한 화면에서 비교
- **점프 호스트(ProxyJump)**: bastion 서버 뒤의 내부 서버에 자동 터널링으로 접속
- **로그인 스크립트(Expect/Send)**: 접속 직후 자동 입력(2단계 인증, alias 실행 등)
- **일괄 전송(브로드캐스트)**: 여러 세션에 동시에 텍스트/파일 전송
- **파일 트리 / 파일 편집기**: SFTP 파일 탐색 + 바로 편집
- **파일 전송 탭**: 로컬 ↔ 원격 드래그 앤 드롭 파일 전송

## 탭 격리 아키텍처

각 워크스페이스 탭(브라우저/오피스/SQL Tool 등 무거운 기능)은 별도의 렌더러 프로세스
(`WebContentsView`)로 분리되어 있어, 한 탭이 무겁거나 응답 없어져도 다른 탭·터미널 세션에는
영향을 주지 않습니다. 백그라운드 탭도 프로세스가 계속 살아있어 SSH 출력이 실시간으로 유지됩니다.
