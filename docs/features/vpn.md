# VPN (OpenVPN)

.ovpn 설정 파일을 가져와 PePe 안에서 바로 OpenVPN 연결을 맺는 워크스페이스입니다.

![VPN 워크스페이스](../screenshots/vpn-01.png)

## 핵심 기능

- **.ovpn 프로필 가져오기**: 여러 프로필을 등록해두고 필요할 때 전환 연결
- **아이디/비밀번호 인증** 또는 인증서 기반 연결 지원
- **실시간 OpenVPN 로그**: 연결 과정의 로그를 그대로 스트리밍해 문제 진단에 활용
- 사내망 뒤에 있는 서버에 SSH 접속하기 전, VPN부터 터미널까지 한 창에서 끝낼 수 있습니다
