# 미디어 워크스페이스

녹취 음원 재생과 pcap(패킷 캡처) 파일에서 RTP 오디오를 바로 추출해 듣는 기능을 제공합니다.

📹 [데모 영상 보기](../videos/media-pcap-rtp-demo.mp4)

## 핵심 기능

- **pcap → RTP → 오디오 추출**: Wireshark 등으로 뜬 패킷 캡처 파일을 열면, 그 안의 RTP
  스트림을 자동으로 찾아 바로 재생 가능한 오디오로 변환합니다. 별도 프로그램 없이 캡처
  파일에서 바로 통화 음질을 확인할 수 있습니다.
- **다양한 코덱 지원**: EVS/AMR/AMR-WB/OPUS 등 통신사 환경에서 쓰이는 코덱 디코딩
- **재생목록**: 여러 음원을 이어서 재생
- **암호화된 녹취 지원**

## 실사용 예시

SSW 소프트폰(MicroSIP)의 패킷 캡처 기능과 연계해, 통화 테스트 중 캡처한 pcap을 바로 이
워크스페이스로 열어 RTP 구간을 추출·청취하는 흐름으로 실제 업무에 사용 중입니다.
