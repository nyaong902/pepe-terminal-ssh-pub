# PePe 원격 공유 / Pepe-Connect

PC 밖에서도 PePe 화면을 보거나 조작할 수 있게 해주는 두 가지 원격 접근 기능입니다.

## PePe 원격 공유 (Tailscale 기반)

![PePe 원격 공유](../screenshots/remote-share-01.png)

- Tailscale 네트워크를 통해 **PePe 창만** 외부 브라우저로 공유 — 바탕화면이나 다른 프로그램은 보이지 않음
- 랜덤 PIN(공유할 때마다 새로 생성) 또는 고정 PIN(항상 같은 6자리) 선택 가능
- 연결된 브라우저에서 PePe 내부 클릭·스크롤·키보드 입력까지 제어 가능 — 원격 지원/시연에 유용

## Pepe-Connect (모바일 QR 연결)

![Pepe-Connect QR](../screenshots/pepe-connect-01.png)

- 사이드 패널의 QR 코드를 모바일 카메라로 스캔하면 Pepe-Connect 앱이 열리며 선택한 인터페이스로 접속
- 여러 네트워크 인터페이스 중 사용할 주소를 선택해 QR을 생성
