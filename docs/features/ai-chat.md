# AI Chat

PePe에 내장된 AI 에이전트 탭입니다. 단순 챗봇이 아니라, 현재 열려 있는 SSH 세션들을 함께
인식한 상태로 명령 실행·로그 분석·설정 수정까지 직접 수행합니다.

## 핵심 특징

- **여러 SSH 세션 동시 인식** — 개발서버·시험서버 세션을 함께 붙여두면, 사람이 정보를 옮겨줄
  필요 없이 AI가 직접 여러 서버를 비교하며 문제를 해결합니다.
- **Claude 기반 에이전트** — Anthropic Claude API로 동작하며, 실제 파일 편집·명령 실행·MCP
  도구 사용까지 가능합니다.
- **VS Code Remote-SSH와의 차이** — VS Code는 접속 대상 서버에 서버 사이드 플러그인(VS Code
  Server)을 설치해 상주시켜 그 장비에 CPU/메모리 부하를 유발합니다. PePe는 대상 서버에
  아무것도 설치하지 않고 로컬에서 SSH로만 접속하므로 장비 부하가 없습니다.
- **Custom LLM 지원** — Claude 외에 OpenAI 호환 API 키를 등록해 다른 모델도 사용 가능

## 보안 참고

세션 정보·인증키는 로컬 PC에만 저장되며 외부로 전송되지 않습니다. 다만 AI Chat 사용 시
서버에서 조회한 화면/로그 내용이 질의 맥락으로 Claude API에 전송될 수 있어, 민감정보가
포함된 화면에서는 사용에 주의가 필요합니다.
