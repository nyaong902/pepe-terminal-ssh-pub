# 파일 전송 워크스페이스

로컬 ↔ 원격(SFTP) 파일을 로컬 탐색기처럼 좌우 듀얼 패널로 드래그 앤 드롭 전송하는
워크스페이스입니다. 터미널에서 이미 접속해둔 SSH 세션을 그대로 재사용하므로 별도 로그인 없이
바로 파일 목록이 뜹니다.

## 핵심 기능

- **좌우 듀얼 패널** — 왼쪽 로컬 / 오른쪽 원격(또는 둘 다 원격), 각각 독립적으로 경로 이동
- **소스 드롭다운**: 🟢 이미 연결된 세션 / ⚪ 미연결 세션(선택 시 자동 백그라운드 SFTP 연결)
  으로 그룹 표시 — 새로 로그인할 필요 없이 클릭 한 번으로 전환
- **드래그 앤 드롭 전송** — 파일/폴더를 반대쪽 패널로 끌어놓으면 전송 시작. 폴더는 재귀적으로
  전체 트리를 순회하며 전송
- **전송 로그 탭** — 진행률/속도/남은 시간/경과 시간을 실시간으로 표시, 완료 후에도 이력 확인
- **충돌 처리** — 대상에 동일 파일이 있으면 덮어쓰기/건너뛰기/이름변경/이어받기(resume) 중 선택,
  "모두 적용"으로 같은 배치의 나머지 파일에도 일괄 적용
- **일괄 텍스트/파일 전송** — 여러 세션에 동시에 같은 파일을 뿌리는 브로드캐스트 전송(별도 다이얼로그)

## ClearCase 동적 뷰(dynamic view) 지원

`setview`로 진입한 ClearCase 동적 뷰 세션(`/vobs/...` 경로)에서도 파일 목록·다운로드·업로드가
정상 동작합니다. 내부적으로 터미널 프롬프트에서 뷰 태그(예: `(ghj_view)`)와
`CLEARCASE_ROOT` 환경변수를 인식해, SFTP 요청을 실제 뷰 경로(`/view/<태그>/vobs/...`)로
자동 변환합니다 — 화면에는 평소처럼 `/vobs/...` 경로로 보이지만, 뒤에서 알아서 뷰 경로로
접근하기 때문에 대용량 VOB 파일(예: 스크린샷의 `.tgz` 빌드 산출물)도 "No such file" 에러 없이
정상적으로 받을 수 있습니다.
