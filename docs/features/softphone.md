# 소프트폰 (MicroSIP / SSW)

MicroSIP과 SSW(SK브로드밴드 PBX) 두 종류의 SIP 소프트폰 워크스페이스를 제공합니다. 둘은
화면뿐 아니라 내부적으로도 완전히 독립된 sipd.exe 엔진 프로세스로 동작해, 한쪽이 죽거나
재시작해도 다른 쪽 통화·등록 상태에는 전혀 영향을 주지 않습니다.

## 기존 SIP 소프트폰과의 차이

단순히 "따로 있던 프로그램을 하나로 합친 것"이 아니라, 가져온 기능들이 PePe 안에서 서로
연동되면서 원래 독립 프로그램보다 더 강력해졌습니다.

- **Call Flow 시각화** — 통화 시퀀스를 다이어그램으로 실시간 표시, 메시지 클릭 시 상세 확인
- **실시간 SIP 메시지 로그** — REGISTER/INVITE/200 OK 등 프로토콜 메시지를 목록/시퀀스/전문
  3가지 보기로 확인
- **상용 코덱 지원** — 기존 툴이 제공 못한 EVS/AMR-WB 등 코덱까지 지원해 실제 시험 환경과
  동일한 조건으로 호 테스트 가능
- **단말별 독립 마이크/스피커 + 볼륨** — 여러 단말을 동시에 다른 오디오 장치로 라우팅
- **SSW 부가서비스** — 단말 카드에서 바로 CFU(착신전환)/CFB(통화중전환)/CTR(호전환) 등 SK
  브로드밴드 PBX 전용 스타코드를 실행. 카드 옆에 인라인으로 펼쳐지며, 여러 단말을 동시에 열어
  비교 가능
- **패킷 캡처** — 통화 중 RTP/SIP 패킷을 바로 캡처해 문제 진단

## 설치 시 선택 설치

설치 프로그램에서 MicroSIP/SSW 소프트폰을 각각 독립적으로 켜고 끌 수 있습니다(용량 절감).
