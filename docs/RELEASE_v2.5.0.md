# v2.5.0

**AI 챗 대화방에 동료를 초대해 함께 이어갈 수 있습니다.** 같은 대화를 여러 사람이 보면서 각자
질문하고, 누가 작업 중인지 서로 보이고, 한쪽이 PC 를 꺼도 나머지가 계속 진행할 수 있습니다.

## 👥 공동 작업방

메신저의 온라인 동료에게 초대를 보내면, 수락한 사람의 PePe 에 같은 대화가 생깁니다. 그 뒤로는
누가 무엇을 물었고 AI 가 무엇을 답했는지가 서로에게 그대로 흐릅니다.

- **각자 질문할 수 있습니다** — 관전이 아니라 함께 쓰는 대화입니다
- **한 번에 한 사람만** 돌립니다. 남이 작업 중이면 상단에 `🔒 김철수 작업 중` 이 뜨고 내 입력은
  대기열로 갑니다 — 잠금이 풀리면 자동으로 나갑니다
- **글자가 실시간으로 흐릅니다.** 상대가 받고 있는 답이 내 대화창에도 같이 찍힙니다
- **초대한 사람을 내보낼 수 있고, 다시 부를 수도 있습니다.** 다시 부르면 내보낸 동안 놓친 내용을
  전부 받아 따라잡습니다
- 미니탭과 대화 목록에 `👥3` 배지가 붙어 어떤 대화가 공유방인지 바로 보입니다
- 공유를 끝내면 각자의 사본은 평범한 대화로 남습니다. 대화 내용은 그대로입니다

### 호스트가 꺼져도 멈추지 않습니다

이게 구조를 결정했습니다. "호스트 PC 에서만 AI 를 돌리고 나머지는 중계" 로 만들면 호스트가 꺼진
순간 아무도 아무것도 못 합니다. 그래서 **각자 자기 PC 에서 AI 를 돌리고, 대화 기록만 서로
복제·병합**합니다.

대화방은 **덧붙이기만 하는 이벤트 로그**입니다. 각 PC 가 사본을 갖고, 만나면 서로에게 없는
이벤트를 주고받습니다. 호스트를 거치지 않고 멤버끼리 직접 붙기 때문에, 호스트가 없는 동안에도
남은 사람들끼리 계속 동기화됩니다.

호스트가 돌아오면 그동안의 작업이 순서대로 합쳐집니다. 순서는 모든 PC 에서 같습니다 — 같은
이벤트 집합을 본 사람은 같은 순서를 얻습니다.

> **미리 알아두실 것**
>
> - 참가자마다 자기 계정으로 자기 AI 를 돌리므로 **비용이 사람 수만큼 듭니다.**
> - **툴이 실행되는 곳이 사람마다 다릅니다.** 남이 세운 계획을 내가 이어받으면 **내 디스크, 내 SSH
>   서버**에 씁니다. 특히 SSH 세션을 붙인 대화에서는 권한 확인 없이 실행되므로, 공동 작업방에서는
>   상대가 만든 계획을 그대로 승인하기 전에 무엇을 실행하는지 확인해 주세요.
> - **상대 PC 에 이미 간 사본은 지울 수 없습니다.** 내보내기는 "이후 동기화를 끊는 것" 이고, 그
>   사람이 이미 받은 내용은 그 PC 에 남습니다.
> - 보안은 사내 LAN 을 신뢰하는 가정 위에 있습니다. 방 비밀값으로 "이 방의 멤버인가" 는 확인하지만,
>   멤버끼리의 사칭은 막지 못합니다.

### 규모에 맞게 동작합니다

이벤트 4,001개(로그 3.9MB) 방으로 실측한 값입니다.

| | |
|---|---|
| 한 턴 기록 | 1 ms |
| 처음 들어와 전부 받기 | 346 ms |
| 받는 중 표시 | `⬇ 내용 받는 중 1400/4001` |

새 이벤트를 만들 때마다 로그 전체를 다시 읽던 것을 방별 색인으로 바꿔 **턴 기록이 84ms → 1ms**
가 됐습니다(2,000턴 방 기준). 통째로 받아오는 동안 화면을 청크마다 다시 그리던 것도 묶어
**21번 → 2번**으로 줄였고, 접속할 때 로그가 두 번 흐르던 낭비도 없앴습니다.

## ⌨ 입력창에서 방향키로 지난 질문 꺼내기

터미널처럼, 입력창이 비어 있을 때 `↑` / `↓` 로 최근에 보낸 질문을 꺼내 씁니다. 세션 편집의 정규식
토글에는 무엇을 켜는 것인지 설명하는 툴팁을 붙였습니다.

## 🔧 곁들여 고친 것들

공동 작업방을 만들다 드러난, 전부터 있던 문제들입니다.

- **분리 창에서 AI 응답이 오지 않던 문제** — 워크스페이스 탭을 떼어내 질문하면 답이 아예 오지
  않았습니다
- **두 창에서 각각 대화하면 한쪽이 사라지던 문제** — 각 창이 자기 스냅샷으로 파일을 덮어써서,
  분리 창에서 만든 대화가 재시작 후 없어졌습니다. 이제 항목 단위로 저장합니다
- **연속으로 보내면 응답이 섞이던 문제**
- **대화이력을 갔다 오면 스크롤이 맨 위로 가던 문제** — 이력 패널이 열리면 대화 영역이 숨겨지는데,
  그 숨은 상태(높이 0)를 "보던 자리" 로 기억해 덮어쓰고 있었습니다. 이제 이력을 갔다 와도, 패널만
  닫아도 보던 자리로 돌아옵니다
