# v2.2.23

## AI Chat에 SSH 세션을 붙여두면 자꾸 끊기던 문제 수정

AI Chat 탭에 SSH 터미널을 붙여놓고 쓰면 `SSH 오류: argument must be a string` → `SSH 오류: Not
connected` → 재연결 루프가 반복되던 버그를 고쳤습니다. 원인은 EUC-KR 등 non-UTF-8 인코딩 세션에서
명령어를 세션 인코딩 바이트로 변환한 `Buffer`를 만드는데, 이 값이 워커 스레드로 프록시되는 SSH
연결(`conn.__isWorkerConnProxy`)에서는 워커 안의 실제 ssh2 클라이언트 `.exec()`가 `Buffer` 인자를
거부하며 예외를 던져 세션 전체가 죽어버리는 것이었습니다. 워커 프록시 경로일 때는 인코딩 변환 없이
원본 UTF-8 문자열을 그대로 보내도록 수정했습니다(`electron/sshBridge.ts`).

## SSW 소프트폰을 MicroSIP과 완전히 별도 컴포넌트로 분리 + 독립 엔진화

지금까지 SSW 소프트폰은 MicroSIP과 같은 화면 컴포넌트를 `sswMode`로만 다르게 그리는 방식이었는데,
서로 다른 SIP 계정을 써도 화면/데이터가 절대 안 섞이도록 `SswSoftphoneWorkspace.tsx`를 완전히
별도 컴포넌트로 새로 분리했습니다(공용 타입/헬퍼는 `src/utils/sipShared.ts`). 이번 버전에서
한 걸음 더 나아가, 내부적으로 공유하던 sipd.exe 엔진 프로세스도 워크스페이스별로 완전히
독립시켰습니다 — 자세한 내용은 아래 "MicroSIP ↔ SSW 소프트폰 엔진 완전 분리" 참고.

## 단말별 마이크/스피커·볼륨 설정

MicroSIP/SSW 소프트폰의 마이크·스피커 장치 및 볼륨 선택을 전역 헤더에서 각 단말 카드로
옮겼습니다 — 단말마다 다른 오디오 장치/볼륨을 쓸 수 있습니다. 설정은 카드를 뒤집으면(flip)
나오는 뒷면으로 이동했고, 워크스페이스 탭을 닫으면 등록된 계정을 자동으로 끊어(hangup/unregister)
같은 로컬 포트를 다른 워크스페이스가 바로 재사용할 수 있게 했습니다.

## 설치 시간 대폭 단축 (~40%)

미디어(GStreamer)/오피스 기능이 추가된 뒤로 설치에 5분 가까이 걸리던 문제를 근본적으로 고쳤습니다.
electron-builder는 설치 시 모든 리소스를 통짜 7z 하나로 묶어 무조건 전부 압축 해제한 뒤에야
`customInstall`이 실행되는 구조라, 지금까지는 "기능 선택" 체크박스를 해제해도 일단 전부 풀고 나서
안 쓰는 폴더를 뒤늦게 지우는 식이라 체크 해제가 설치 시간에 전혀 도움이 안 됐습니다.

- 각 선택 기능(VPN/MicroSIP/SIPp/미디어/오피스)을 빌드 시 zip 파일 하나로 미리 압축해 하나의
  파일로만 번들 — 체크 해제 시 그 압축 해제 자체를 완전히 건너뛰도록 개선
- 파일 수가 가장 많던 X11 서버(VcXsrv, 약 5천 개 파일) 번들도 zip+tar 방식으로 전환해
  설치 시 파일 복사 단계를 크게 단축
- 실측 기준 설치 시간 약 115초 → 약 69초로 단축 (전체 기능 설치 기준)

## 포터블 빌드 호환성

포터블(exe 단일 실행) 빌드는 NSIS 설치 과정을 거치지 않아 위 zip들이 그대로 안 풀린 채로
남을 수 있는데, 이번 버전부터는 앱이 각 기능을 실제로 처음 사용하는 시점에 해당 zip을 그때
풀어주는 지연 추출 로직을 추가해 설치 방식과 무관하게 항상 정상 동작합니다.

## MicroSIP ↔ SSW 소프트폰 엔진 완전 분리

지금까지 MicroSIP과 SSW 소프트폰 워크스페이스는 화면(UI)은 분리돼 있었지만 내부적으로 같은
sipd.exe 프로세스(엔진) 하나를 공유했습니다. 이번 버전부터는 각 워크스페이스가 완전히 독립된
sipd.exe 프로세스를 따로 띄우도록 바꿨습니다 — 설치 파일은 그대로 하나만 공유하지만(추가 용량
없음), 실행 시에는 완전히 별개의 프로세스라 한쪽이 죽거나 재시작해도 다른 쪽 통화·등록 상태에는
전혀 영향을 주지 않습니다.

## 프로비저닝(내보내기/가져오기) 툴바 UX 수정

- 내보내기/가져오기 화살표 방향이 반대로 붙어있던 것을 고쳤습니다 — 내보내기 ⬆, 가져오기 ⬇.
- 단말이 0대인 초기 상태에서는 툴바 자체가 안 보여서 가져오기를 쓸 수 없던 문제를 고쳤습니다.
  이제 단말이 없어도 툴바가 보이고, 가져오기는 바로 쓸 수 있습니다(내보낼 게 없는 내보내기
  버튼만 비활성화).
- "단말이 없습니다" 안내 문구가 주소록/매크로 등 무관한 탭에도 뜨던 것을 단말 탭 전용으로,
  또 툴바보다 아래에 오도록 위치를 바로잡았습니다.
- SSW 소프트폰에서 설정을 내보낼 때 파일명이 `microsip-config.json`으로 잘못 붙던 복붙 실수를
  고쳐 `ssw-softphone-config.json`으로 나가도록 했습니다.

## 메신저 첨부(이미지/파일) 미리보기·저장 기능 추가 및 버그 수정

- 채팅창에 이미지 미리보기가 안 보이던 근본 원인을 고쳤습니다: 붙여넣기/드래그로 첨부한 파일은
  임시 폴더에 저장됐다가 전송 성공 시 바로 삭제됐는데, 정작 보낸 메시지의 말풍선은 그 삭제된
  경로를 계속 가리키고 있어서 "내가 보낸" 이미지가 항상 깨져 있었습니다. 이제 받은 파일과
  동일하게 영구 보관 폴더로 옮긴 뒤 전송하도록 고쳐서 미리보기가 정상적으로 뜹니다.
- 붙여넣기 첨부 시 표시되던 원본 파일명("스크린샷 2026-...")이 전송 후 무작위 임시 파일명으로
  바뀌어버리던 것도 함께 고쳐, 보낸 메시지에도 원래 이름이 그대로 남습니다.
- 파일/이미지/스티커 메시지에 "저장"(다른 이름으로 저장) 버튼을 추가했습니다. 앱이 자동
  보관 중인 사본(임시 폴더)만 저장 대상이면, 저장 후 그 사본은 삭제하고 메시지가 가리키는
  위치도 새로 저장한 곳으로 갱신됩니다 — 사용자가 📎 버튼으로 직접 고른 원본 파일은 항상
  보존되며 절대 건드리지 않습니다. 보낸 메시지·받은 메시지 모두 동일하게 적용됩니다.
- 버튼 UX는 브라우저 다운로드바와 동일하게: 아직 저장 안 한 첨부는 내부 임시 경로를 감추고
  "저장" 버튼만, 저장을 완료하면 "폴더 열기" 버튼만 보여줍니다.
