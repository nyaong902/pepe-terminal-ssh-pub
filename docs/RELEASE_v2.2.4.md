# v2.2.4

## v2.2.3의 자동 업데이트 회귀 수정

v2.2.3에서 "다른 PC에서 자동 업데이트 설치 창이 안 뜬다"를 고친다며 판단 기준을 `--updated` 존재 여부에서 진짜 무음 설치 여부(`${Silent}`, `/S` 플래그)로 바꿨는데, 실제로는 이게 v2.2.1에서 이미 같은 문제를 고쳤던 수정(`--updated`면 무조건 건너뛰기)을 되돌려 문제를 재발시킨 것이었습니다.

- 사용자 데이터 삭제 확인 페이지 / 기능 선택 페이지 모두, `--updated`(자동 업데이트)로 실행된 경우 다시 무조건 건너뛰도록 원복. 이 두 인터랙티브 nsDialogs 페이지가 관리자 권한/그룹정책 환경이 다른 PC의 백그라운드 자동 업데이트 흐름에서 안정적으로 뜨지 않는 게 실제 원인이었고, 안 띄우는 게 검증된 해결책이었습니다.
- 자동 업데이트 중에는 이전 설치 때 레지스트리에 저장해둔 선택값을 그대로 재적용합니다(기능 선택을 바꾸려면 설치 파일을 직접 실행하세요).
