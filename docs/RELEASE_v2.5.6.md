# v2.5.6

**창 아래위의 바들이 이제 화면 끝에서 끝까지 갑니다.** 그리고 AI Chat 에서 대화를 통째로
지우는 것 말고 **메시지 하나씩** 골라 지울 수 있습니다.

## 🖥 상태바 · 도구모음 · 일괄전송 바 — 화면 전체 폭

세 바가 모두 왼쪽 사이드바 **오른쪽에서만** 시작했습니다. 그래서 화면 왼쪽 아래에는 상태바가
아예 없었고, 도구모음도 사이드바를 비켜 갔습니다.

- 셋 다 창 전체 폭을 씁니다. 세션 관리·파일트리는 그만큼 위아래로 비켜 줍니다
- 세로 트리거(`세션 관리` / `파일 트리` / `AI Chat`)의 글자와 아이콘이 바에 가려지던 것,
  워크스페이스 탭·세션·파일 **우클릭 메뉴 아래쪽이 잘리던 것**도 함께 고쳤습니다

> 바 높이를 숫자로 박아두지 않고 실제 높이를 재서 씁니다. 예전에는 조합(빠른연결 바 유무,
> 도구모음 위치)마다 68 / 72 / 104px 같은 값이 코드에 흩어져 있었습니다.

## 🗑 AI Chat — 메시지 하나씩 지우기

전체 삭제밖에 없어서, 잘못 물어본 질문이나 빗나간 답변 **하나만** 걷어낼 수 없었습니다.
남겨두면 다음 질문에 그대로 다시 딸려 들어갑니다.

- 메시지 **우클릭 → `🗑 이 메시지 삭제`**. 되돌릴 수 없어서 복사 항목들과 떼어 붉게 뒀습니다
- 그 답변이 실행한 도구 줄도 같이 사라집니다 — 답변만 지우면 그 답변이 부른 도구 줄만
  뜬금없이 남습니다. 질문을 지울 때는 도구를 건드리지 않습니다(어느 답변 것인지 알 수 없음)
- 지금 답변을 받고 있는 중인 메시지는 지워지지 않습니다(지워도 이어지는 글자가 되살립니다)

### 전체 삭제 확인은 말풍선으로

🗑 을 누르면 화면 한가운데 큰 모달이 떴습니다. 탭을 닫을 때와 같은 **작은 말풍선**으로 바꿨습니다
— ESC 취소, Enter 확인, 바깥 클릭이면 닫힘. 내용이 없는 대화는 묻지 않고 바로 지웁니다.

## 🤖 AI Chat — 에이전트 정리

- **Gemini 를 뺐습니다** — AI Chat, DB 워크스페이스, 로그 분석 세 곳의 에이전트 선택에서
  사라집니다. 예전에 Gemini 로 나눈 대화는 그대로 보입니다
- **API 키 관리에 GitHub 칸이 생겼습니다.** Copilot 은 `gh auth login` 토큰을 그대로 쓰는 게
  정상 경로인데, 그게 안 될 때 쓰는 수동 토큰을 **넣을 칸이 아예 없었습니다**
- 키 목록의 아이콘을 에이전트 전환 줄과 같은 것으로 맞췄습니다(이모지 → 브랜드 아이콘)

## 그 밖에

- **빠른 명령**을 라벨 없이 **아이콘만으로** 저장할 수 있습니다. 둘 다 비었을 때만 막습니다
- **분할 문구를 좌우/상하로 통일**했습니다. `가로 분할 (좌/우)` 처럼 "가로/세로" 가 칼선
  방향인지 패널 배치인지 헷갈렸고, 실제로 메뉴마다 뜻이 반대로 붙어 있었습니다.
  이제 `좌우 분할` / `상하 분할` 로 방향을 그대로 말합니다(5개 언어)
