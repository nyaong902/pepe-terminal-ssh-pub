# v2.2.20

## v2.2.15로 복귀 — perMachine:false는 원인이 아니었음

v2.2.19에서 perMachine:false(사용자별 설치, 관리자 권한 불필요)로 바꿔봤지만, 문제가 재현되던 PC에서 여전히 설치 창이 안 뜨는 게 확인됐습니다. 관리자 권한/UAC가 원인이 아니라는 뜻입니다.

되짚어보니 v2.2.19로 넘어가면서 실수가 있었습니다 — 관리자 권한 문제와는 별개로 이미 두 번(v2.2.16, v2.2.18) 확인된 "자동 업데이트 중 커스텀 페이지를 보여주면 설치 창이 안 뜬다"는 문제를, perMachine 전환 작업 중에 실수로 다시 켜둔 채로 남겨뒀습니다.

- `perMachine: true`(전체 사용자용 설치)로 복귀 — v2.2.15와 동일한 설정
- 레지스트리 경로(HKCU→HKLM), 설치 경로(`Program Files`), `SetShellVarContext` 처리 모두 v2.2.15 상태로 복귀
- 자동 업데이트 중 커스텀 페이지(사용자 데이터 삭제 확인, 기능 선택)는 다시 무조건 건너뜀 — v2.2.15에서 그 PC에 확실히 검증됐던 설정

정리하면 v2.2.20은 사실상 **v2.2.15와 동일한 설치 동작**입니다(무해한 안전장치 몇 개만 추가). v2.2.15가 그 PC에서 정상 동작했으니 이번에도 정상 동작해야 합니다.
