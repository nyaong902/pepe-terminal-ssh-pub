# v2.6.5

**Pepe-Zip**(압축/JNLP 실행) 워크스페이스가 새로 들어갔고, **CDR 도구**에 통계·품질통계
탭이 생겼습니다. **소프트폰**은 단말을 그룹으로 나눠 볼 수 있고, 세션 이름이 조용히
바뀌어 저장되던 문제와 Oracle 테이블 목록이 비어 보이던 문제를 고쳤습니다.

## 🗜 Pepe-Zip — 압축과 JNLP 실행을 앱 안에서

따로 쓰던 PePe Zip 을 워크스페이스로 들여왔습니다. 7-Zip 을 그대로 쓰므로 압축/해제
결과는 같고, 앱 안에서 탭으로 엽니다.

- **압축/해제**를 작업 대기열로 돌립니다 — 여러 개를 걸어 두고 진행 상황을 봅니다
- **JNLP 실행기**: 자산관리툴처럼 Java Web Start 로 뜨는 화면을 앱 안의 뷰로 띄웁니다.
  **번들 Zulu JRE 8** 을 먼저 쓰고, JAR 매니페스트의 Main-Class 를 찾아 실행합니다.
  네이티브 라이브러리 추출, 메인 JAR 우선 클래스패스, JAR 갱신 확인(오프라인이면 캐시
  사용), 콘솔 창 안 뜨게 하기까지 들어 있습니다
- 워크스페이스 **인스턴스별로** 상태를 따로 들고 있습니다 — 탭을 두 개 열어도 서로
  섞이지 않습니다

## 📈 CDR 도구 — 통계 / 품질통계

standalone 원본 도구의 새 버전에서 기능과 판정 로직을 들여왔습니다.

- **📊 통계**: 고른 필드 조합별로 통화를 셉니다. 집계 단위가 (CallID + CallLogType) 이라
  같은 통화의 같은 유형 leg 가 여러 줄이어도 **1건**입니다. 필드 검색(`%LIKE%`), 순서
  변경, 피벗(마지막 필드를 열로), 정의값 의미, 호 유형 선택을 지원합니다. 행이나 숫자를
  누르면 **🔎 통계 상세 CLOG** 탭에서 그 CallID 의 전체 호 흐름을 같은 필드/판정/그룹으로
  보여줍니다
- **📶 품질통계**: `SigType=7` leg 의 RTCP(90 손실 / 91 지터 / 92 지연)로 **회선(IP +
  C슬롯/span) × 코덱별** 좋음·보통·나쁨을 집계합니다. RTE 는 방향까지 표기하고, 행을
  누르면 그 회선의 CLOG 로 내려갑니다
- 둘 다 **엑셀로 내보냅니다**
- **판정 로직 신버전**: 시스템 절체(설정 중/통화 중), SIP ACK 미수신, SIP INVITE 무응답,
  Digest 인증 미완료, 번호이동 NPDB 질의/조건 불충족, 운용자·시스템 강제 종료, 번호이동
  RN 병기. 진단 툴팁에 강조 토큰이 들어와 호 흐름·Q850/FC·LS 결과가 눈에 띕니다. 통화
  품질 배지와 라우팅 진단(Network Code 30, 0AC+PFX)도 함께 붙습니다
- **입력 파싱**: grep 파일명 접두어(`xxx.dat:`) 제거, `cat` 줄바꿈 복원, CDR 헤더/접두어
  줄 걸러내기
- **필터를 CallID 단위로** 겁니다 — 발신 leg 에만 있는 값으로 찾아도 그 통화의 착신·중계
  leg 가 함께 나와야 호 흐름을 읽을 수 있습니다. 필드별 DN 검색 줄(발신/착신/대표/원번호/
  과금번호 등 7칸)과 `CallLogType[6]` 필터도 생겼습니다

### 📌 컬럼 고정이 먹지 않던 문제

판정열이 켜져 있으면 📌 를 눌러도 아이콘이 켜지지도, 열이 고정되지도 않았습니다(제보:
PAIR CALLSUBID 고정 안 됨). 제자리 갱신 경로가 **판정 3칸을 세지 않아** 늘 세 칸씩
어긋나 있었습니다. 판정은 CLOG 변환 직후 자동으로 켜지므로 사실상 항상 그랬습니다.

## ☎ 소프트폰 — 그룹으로 나눠 보기, 카드 끌어서 옮기기

SSW 소프트폰과 MicroSIP 양쪽에 같이 들어갑니다.

- 단말이 늘어나면 한 화면에 안 들어와 찾기 어려웠습니다. 단말/통화기록 화면에
  **`전체 · 그룹들 · 미지정 · + 그룹`** 탭 줄이 생겼습니다
- 카드 **그립(⠿)을 잡아 그룹 탭에 떨어뜨리면** 그 그룹으로 옮겨집니다. ⚙ 설정면의
  그룹 선택칸으로도 바꿀 수 있고, 이때 카드는 통화면으로 되돌아옵니다
- 탭 **더블클릭으로 이름 변경**, 그룹을 지워도 단말은 미지정으로만 옮깁니다
- **콜로그·통화기록·전문 로그**도 선택한 그룹의 단말 것만 보여주고, 통화기록 전체 삭제도
  보이는 것만 지웁니다
- 카드를 **끌어서 자리 옮기기**: 그립을 잡아 다른 카드 위에 놓으면 그 자리로 들어가고
  나머지가 한 칸씩 밀립니다. 지금까지는 설정면으로 뒤집어야 나오는 ▲▼ 로만 한 칸씩
  옮길 수 있었습니다(▲▼ 는 그대로 둡니다 — 한 칸씩은 그쪽이 정확합니다)

## 🤖 AI Chat

- **응답 중에 끼어들어도 그때까지의 도구 기록이 남습니다.** 보낼 때마다 도구 목록을
  통째로 비우고 있어서, 말풍선은 그대로인데 "실행 N개" 만 사라져 **하던 작업이 통째로
  날아간 것처럼** 보였습니다(제보). 끼어들기로 취소된 항목은 ⏳ 로 영원히 남지 않게
  중단으로 마감합니다
- **대화 전체 복사.** 말풍선 우클릭 메뉴에 생겼습니다. 화면에 보이는 그대로 — 말풍선과
  도구 기록을 순서대로 섞어 — 마크다운으로 복사합니다
- **다이어그램을 밝은 테마로 보고 복사/저장하면 배경만 까맣게** 나왔습니다. 선 위의
  글자는 밝은 테마 색 그대로라 그 배경에 묻혀 보이지 않았습니다(제보). 지금 테마의
  배경색으로 굽습니다
- **표 복사 버튼**이 표 머리글 위에 겹쳐 떠서 한 칸을 가렸고, 그래서 버튼이 있는 줄도
  모르고 지나쳤습니다(제보). 표 위에 자리를 내주고, 좁은 표에서 버튼만 화면 끝에
  떨어져 있던 것도 고쳤습니다

## 🗂 세션 이름이 조용히 바뀌어 저장되던 문제

세션 이름을 고쳐 저장해도 그대로더라는 제보. 저장은 되는데 **트리 전체**에서 같은
이름을 찾아 ` 2` 를 다시 붙이고 있었습니다. 같은 장비를 쓰임새별로 여러 폴더에 등록해
두는 건 흔한 일이라 **폴더가 다르면 이름이 같은 게 정상**입니다.

- 겹치는지를 **같은 폴더 안에서만** 봅니다. 복제본이 같은 이름으로 쌓이는 것을 막던
  원래 목적은 그대로 지켜집니다(복제본은 같은 폴더에 생깁니다)
- 그래도 꼬리표가 붙는 경우에는 **알려 줍니다** — 예전에는 조용히 바꿔 버려서 "이름을
  바꿨는데 안 바뀐다" 로 보였습니다

> 이미 ` 2` 가 붙어 저장된 이름은 그대로 남아 있습니다 — 다시 이름을 고치면 이제
> 반영됩니다.

## 🗄 SQL 도구 — Oracle 테이블 목록이 비어 보이던 문제

상용 Oracle 세션에 접속하면 자기 계정 스키마인데도 목록이 비어 있었습니다(제보).
권한 문제가 아니라 **시간 초과**였고, 그 실패가 세 군데에서 전부 **빈 목록으로
둔갑**해서 권한인지 시간 초과인지 정말 없는 건지 구분할 수 없었습니다.

- Oracle 은 사전(`ALL_TABLES`/`ALL_VIEWS`)을 **OWNER 로 바로** 조회합니다 — 훨씬 빠르고
  결과가 분명합니다. 실패하면 예전 방식으로 물러납니다. 다른 DBMS 는 그대로입니다
- **실패를 삼키지 않습니다** — 트리의 그 자리에 사유가 빨간 줄로 뜹니다
- 행 상한 5,000 → 20,000

  긁는데, **그 사이 — 워크스페이스 하나 전체 —** 를 고를 수가 없었습니다. 📤 파일전송
  창의 대상 선택칸도 같습니다
- **Ctrl+Tab** 이 분할 화면 오른쪽에서는 첫 번째 페인의 미니탭을 돌리던 것을 고쳤습니다
  — **키보드 포커스가 있는 페인**의 미니탭만 돕니다
- **폴더 비교**가 크기만 보고 같다고 판단해서, 글자 수가 그대로인 수정(예: 16자 경로를
  다른 16자 경로로 교체)을 **"같음"** 으로 보여줬습니다. 256KB 이하 동일 크기 파일은
  내용을 해시로 확인해 **"변경됨"** 으로 잡습니다
