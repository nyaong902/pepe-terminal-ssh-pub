# v2.5.8

**AI Chat 의 Codex 모델 목록이 이제 스스로 최신입니다.** 앱에 적어둔 목록이 실제와 어긋나
접속이 안 되던 문제를 고쳤습니다.

## 🤖 Codex — 없는 모델로 접속을 시도하던 문제

앱이 모델 목록을 코드에 적어두고 그중 하나를 기본값으로 넘기고 있었습니다. 그 결과:

- 그 모델을 쓸 수 없는 계정에서는 **`404 ... does not exist or you do not have access to it`**
  이 뜨며 재접속만 반복했습니다
- 적어둔 다른 모델은 Codex CLI 가 이름조차 몰라 **`Model metadata not found`** 경고가
  떴습니다. 이건 계정과 무관하게 모든 PC 에서 났습니다

적어둔 목록이 실제와 완전히 달랐습니다. 지금 Codex 의 현재 모델은 `GPT-6-Astra` 이고,
앱이 기본값으로 쓰던 `GPT-5.5` 는 이미 이전 세대입니다.

### 목록을 Codex CLI 에게 물어봅니다

이제 앱이 목록을 갖고 있지 않습니다. **Codex CLI 에 직접 물어봐서** 채웁니다 — CLI 의
`/model` 화면에 나오는 것과 같은 목록이고, 설명도 함께 받아 항목 위에 올려둡니다.
Codex 가 업데이트되어 모델이 바뀌어도 앱은 그대로 따라갑니다.

### 기본값은 "Codex 기본값" 입니다

모델 선택 맨 위에 **`⚙ Codex 기본값`** 이 생겼고, 이것이 새 기본값입니다. 이 경우 앱이
모델을 지정하지 않고 **Codex 가 알아서 고르게** 둡니다 — 계정 등급이나 CLI 버전을 타지
않는 유일한 선택입니다.

특정 모델을 쓰고 싶으면 예전처럼 목록에서 고르면 됩니다. 다만 계정이나 CLI 버전에 없는
모델을 고르면 접속이 실패한다는 안내를 선택 상자에 붙였습니다.

> 목록을 받아오지 못하는 경우(예: 오래된 Codex CLI)에는 현재 시점의 목록을 대신 보여주고,
> 그것도 맞지 않으면 `⚙ Codex 기본값` 으로 접속할 수 있습니다.
