# v2.2.24

## 기능 선택 페이지를 NSIS 내장 컴포넌트 페이지로 전환

지금까지 자체 제작한 nsDialogs 커스텀 페이지로 기능 선택을 구현했었는데, 이 페이지가 자동 업데이트 중 설치 창이 안 뜨는 문제와 관련 있을 수 있다는 판단하에, NSIS가 기본 제공하는 표준 컴포넌트 선택 페이지(`MUI_PAGE_COMPONENTS`)로 전환했습니다.

- VPN/MicroSIP/SIPp/미디어/오피스 5개 항목을 표준 Section 체크박스로 노출 (각 항목에 설명 텍스트 포함)
- 이전에 저장해둔 선택값(레지스트리)을 페이지의 기본 체크 상태로 반영
- 자동 업데이트 중에도 이 페이지가 뜨도록 함(사용자 데이터 삭제 확인 페이지는 기존처럼 자동 업데이트 시 건너뜀)
- 참고용 진단 로그(`C:\Users\Public\pepe-install-debug.log`)는 이전 세션에서 추가된 그대로 유지

**확인 필요**: electron-builder가 자동 생성하는 앱 본체 설치 섹션이 같은 컴포넌트 목록에 함께 노출될 수 있습니다. 실제 화면에서 이상하게 보이거나 실수로 앱 본체를 체크 해제할 수 있어 보이면 알려주세요 — 추가 보호 처리하겠습니다.
