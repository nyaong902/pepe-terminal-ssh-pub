# v2.5.1

**메신저가 이제 암호화됩니다.** 그리고 v2.5.0 의 공동 작업방을 실제로 써 보며 드러난 것들을
손봤습니다.

## 🔒 메신저 종단간 암호화

메신저 전송 실패를 조사하다 **TCP 트래픽이 전부 평문(JSON)으로 오가고 있다**는 것이
드러났습니다. 사내망 어디서든 들여다볼 수 있는 상태였습니다.

- **X25519 ECDH**(hello 로 공개키 교환) + **AES-256-GCM** 으로 암호화합니다
- 구버전 상대와는 평문으로 내려갑니다(하위호환) — 그래서 상대별로 **🔒 / 🔓 배지**를 대화창
  제목 옆에 띄웁니다. 상대도 새 버전이어야 잠깁니다

> 같은 조사에서 **사내망의 어떤 장비가 UDP 브로드캐스트의 소스 IP 를 다시 쓴다**는 것도 실측으로
> 확인했습니다(서로 다른 두 사용자가 동시에 같은 IP 로 보였습니다). 유니캐스트 응답으로 온 주소를
> 가장 믿고, 관찰된 여러 IP 를 기억해 실패 시 다시 시도하도록 우회했습니다.

## 📩 메신저

- **전송 실패가 보입니다.** 예전에는 실패하면 입력만 사라지고 흔적이 없었습니다. 이제 "보내는 중"
  이 뜨고, 실패하면 **사유(피어 오프라인 / 타임아웃 / 연결 오류)와 함께 재전송·취소** 버튼이 남습니다
- **이미지를 앱 안에서 봅니다.** 클릭하면 파일탐색기로 나가지 않고 바로 크게 뜹니다.
  `− 100% +` 버튼, 휠, 우클릭, 키보드 `+` `-` `0` 으로 배율을 바꿉니다. 배경 클릭이나 `ESC` 로 닫습니다
- **첨부만 지울 수 있습니다.** 지금까지는 "이 대화 삭제"(대화 전체)뿐이었습니다. 이제 파일 하나만
  지우고 대화에는 `이미지가 삭제되었습니다.` 자리가 남습니다 — 통째로 없애면 "여기 뭐가 있었는데"
  를 알 수 없습니다. 앱 폴더 밖(저장해둔 곳)의 파일이면 **지울 경로를 확인 창에 보여줍니다**

## 🗒 스티커 메모가 탭이 됐습니다

`AI Chat` / `메신저` / `작업일지` 와 같은 자리에서 열립니다.

**패널을 고정(pin)해두면 스티커 메모로 들어갈 길이 아예 없었습니다** — 우측 트리거 레일이 패널에
덮이는데, 그 레일이 "고정하지 않았을 때만" 그려지기 때문입니다. 그리고 고정하지 않았을 때 뜨던
280px 짜리 떠 있는 창은 같은 목록을 탭에서 볼 때와 다른 모습이었습니다.

여는 길을 탭 하나로 모았습니다 — 트리거 클릭·호버, 단축키, 포스트잇 창의 "노트 목록" 전부.

## 👥 공동 작업방 다듬기

v2.5.0 에서 넣은 기능을 실제로 두 대로 써 보며 나온 것들입니다.

- **대화창 상단에 항상 상태가 보입니다** — `👥 3명 함께 · 2/3 접속` 과 참여자 칩(👑 주인,
  🔒 작업 중, 접속 중은 초록). 잠금 배너는 "누가 작업 중일 때만" 떠서, 아무도 안 돌리고 있으면
  공유방인지 알 수가 없었습니다
- **잠금이 영구히 남던 문제.** 상대가 턴 도중 앱을 껐다 다시 켜면 붙어는 있는데 그 턴을 기억하지
  못해 하트비트가 안 오고, 회수 조건이 "연결 안 됨" 이라 **영원히** 기다렸습니다. 붙어 있어도 2분
  넘게 조용하면 회수하고, 앱을 켤 때 내 이름으로 열린 턴은 내가 정리합니다. 그래도 상대 앱이
  살아 있고 AI 만 멈춘 경우는 구별할 수 없으므로 **`강제 해제` 버튼**과 경과 시간을 뒀습니다
- **대기열에 여러 건이 쌓입니다.** 문자열 하나만 들고 있어서 두 번째 발화가 첫 번째를 덮어썼습니다.
  이제 순서대로 쌓이고 한 건씩 나가며, `대기 3건` 을 눌러 목록을 펼치고 개별 삭제할 수 있습니다
- 메신저에서 초대를 **수락하면 바로 그 방으로** 갑니다. 초대 창에도 `방으로 바로가기` 가 있습니다

## 🚀 앱을 켜면 마지막에 하던 대화가 앞에 옵니다

빈 화면으로 시작해서 어제 하던 대화를 이어가려면 매번 대화이력을 열어 찾아야 했습니다.

고치는 데 세 겹이 얽혀 있었습니다. `updatedAt` 이 **"마지막으로 대화한 시점" 이 아니라 "마지막으로
열려 있던 시점"** 이었고(대화를 그냥 열어만 둬도 시각이 갱신됐습니다 — 실측: 메시지 2개짜리가
44개짜리를 15초 차로 밀어냈습니다), 미니탭 복원이 오래된 포커스를 그대로 열고 있었습니다.

## 🔍 대화 검색

- **이력 패널에서 모든 대화를 가로질러 찾습니다.** 제목과 본문을 훑고, 본문이 맞으면 발췌를 보여줍니다
- **대화 내 검색을 하면 앱 창이 통째로 사라지던 문제.** 하이라이트가 React 가 그린 DOM 을 직접
  `<mark>` 로 쪼개고 있었고, React 가 다음 렌더에서 자기 자식을 못 찾아 예외를 던지며 트리 전체가
  내려갔습니다(작업표시줄에는 남아 있었습니다). DOM 을 건드리지 않는 **CSS Custom Highlight API** 로
  바꿨습니다

## 🔑 1년짜리 Claude 로그인 토큰

구독(Pro/Max) 로그인의 토큰은 짧게 만료돼 자주 다시 로그인해야 했습니다. `claude setup-token` 으로
받는 1년짜리 토큰을 옵션에 넣어두면 그것으로 돕니다.

- 토큰을 넣어도 기존 로그인 세션이 남아 있으면 CLI 가 그쪽을 먼저 쓰는 것을 실측으로 확인했습니다 —
  토큰이 설정되면 설정 디렉터리를 앱 전용으로 격리해 토큰만 쓰게 합니다
- 입력창 아래에 지금 어느 방식으로 붙어 있는지(1년 토큰 / 일반 로그인) 배지로 보여줍니다

## 🔧 그 밖에

  과 같은 별도 채널로 바꿔 완전히 백그라운드로 돌립니다

  문제를 고쳤습니다

  때 함께 지워집니다
