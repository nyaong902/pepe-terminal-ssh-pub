# v2.3.4

## 파일전송 탭 병합 — 분리했던 창을 되돌리면 하나로 합쳐짐

파일전송 탭을 다른 창으로 분리했다가 다시 원래 창으로 끌어다 놓으면, 예전처럼 별개의 새 탭이
생기는 게 아니라 **기존 파일전송 탭 안으로 합쳐집니다**. 창마다 파일전송 탭은 하나만 유지된다는
전제로, 탭바 어디에 놓아도 병합됩니다(다른 워크스페이스 탭 위에 정확히 올리면 기존처럼 순서
재정렬). 같은 창 안에서의 드래그, 서로 다른 창 사이 드래그 모두 지원합니다.

- 각 창은 자기만의 렌더러 프로세스라 연결 식별자를 그대로 옮길 수 없어서, 병합은 "같은
  자격증명으로 새로 연결"하는 방식입니다. 저장된 세션은 세션 정보로, "SFTP 연결"/빠른연결로 맺은
  즉석 연결은 이번에 자격증명을 함께 보존하게 만들어서 재연결합니다
- ClearCase 개발서버의 dynamic view 경로(`/vobs/...`)도 병합됩니다 — 뷰 정보를 새 연결로 넘겨주지
  않으면 접근이 불가능해서, 연결이 바뀔 때마다 이어서 전달하도록 했습니다
- 재연결할 자격증명이 없는 연결은 병합에서 제외되며, 몇 개가 제외됐는지 알림으로 안내됩니다

## 파일전송 — 창 분리/복원 시 재연결·목록 재로딩 제거

창을 분리하거나 되돌릴 때마다 모든 원격 연결이 끊기고 다시 붙으면서 파일 목록이 통째로
재로딩되던 문제를 잡았습니다. 이제 살아있는 연결은 그대로 유지되어 목록이 즉시 표시됩니다.

- 분리 시 보존해둔 연결을 원본 창이 도로 끊어버리던 경합 상태 수정 — 이 때문에 새 창은 매번
  전부 재연결해야 했습니다
- 파일전송이 직접 맺는 SFTP 전용 연결은 터미널 세션이 아니라서 "이미 끊긴 연결"로 잘못 판정되던
  문제 수정
- 재연결이 실제로 필요한 경우(앱 재시작 등)에도 캐시된 목록을 먼저 그려주도록 개선

## 파일전송 — 그 외 수정

- 패널 탭이 많아질 때 스크롤바 대신 워크스페이스 탭바와 같은 `‹ ›` 버튼으로 스크롤합니다.
  `+`/분할/닫기 버튼이 스크롤에 밀려 사라지던 문제도 함께 수정
- 한 패널에서 두 번째 원격 연결을 열면 첫 번째 연결이 끊기던 버그 수정
- 여러 세션이 한 패널에 모였을 때 다른 세션의 경로가 엉뚱한 탭에 적용돼 "Permission denied"가
  나던 버그 수정
- 연결이 끊긴 상태에서 목록 조회가 응답 없이 멈춰 있던 문제 — 이제 명확한 오류로 안내됩니다

## 터미널 — 렌더링/안정성

- 터미널 기본 렌더러를 DOM 방식으로 변경했습니다. 기존 WebGL 렌더러에서 원격 명령이 설정한
  배경색이 지워지지 않고 화면 전체로 번지는 문제(예: ClearCase `vdiff` 출력)가 확인됐습니다.
  개발자 도구에서 `window.__pepeSetWebglDisabled(false)` 로 되돌려 비교할 수 있습니다
- 세션 탭을 닫을 때 간헐적으로 발생하던 터미널 렌더링 크래시 억제

## 그 외

- 다른 앱 창에 완전히 가려진 창 위에 탭을 놓으면, 보이지도 않는 그 창으로 탭이 들어가버리던 문제
  수정 — 좌표만 보지 않고 실제로 커서 아래 최상단에 있는 창인지 확인합니다
- 설치 속도 개선 — JRE(146MB, 300개 이상의 파일)를 다른 대용량 번들과 같은 방식으로 zip 으로
  묶어 설치 시 한 번에 풀도록 변경
- 회사 메신저의 삭제 확인 등이 네이티브 창 대신 앱 내장 모달로 통일
- 진단용으로 남아 있던 콘솔 로그 정리 (SSH 연결마다 출력되던 로그, `[cw-debug]`/`[auto-submit]`
  기본 비활성)
