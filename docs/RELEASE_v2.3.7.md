# v2.3.7

세션 편집기에 XShell 의 설정들을 옮겨오고, 터미널 내용을 편집기로 보내 보는 기능을 넣었습니다.
마크다운 파일을 앱 안에서 읽기 좋게 보여주는 기능도 추가했습니다.

## 🔌 연결이 끊겼을 때 자동으로 다시 붙습니다

접속해두고 두 시간쯤 지나면 `read ECONNRESET` 으로 끊기는데, 그때 **직접 다른 탭을 갔다 와야
재연결이 시작되던** 문제를 고쳤습니다. 이제 끊긴 즉시 재접속 카운트다운이 돕니다.

> 끊김 자체는 앱 문제가 아니었습니다. 같은 시각에 XShell 로 붙여둔 세션도 함께 끊겼고
> (`Socket error Event: 32 Error: 10053`), XShell 은 30초 뒤 조용히 다시 붙어서 끊긴 걸 몰랐던
> 것입니다. 방화벽·VPN 처럼 중간 장비가 세션을 정리하는 것으로 보입니다.

## ⏱ 연결 유지 — 세션마다 설정

세션 편집 > **연결 > 연결 유지** 에 XShell 과 같은 세 가지가 생겼습니다.

| 항목 | 기본값 | 무엇을 하나 |
|---|---|---|
| 연결 유지 메시지를 보냄 + 간격 | 켬 / 60초 | SSH 수준으로 살아있음을 알립니다 |
| 유휴 상태일 때 문자열을 보냄 + 간격 + 문자열 | 끔 | 원격 셸에 실제 입력을 보냅니다 |
| 유휴 상태일 때 TCP 연결 유지 패킷 | 끔 | TCP 수준으로 알립니다 |

세 가지가 **각각 다른 계층**이라는 점이 중요합니다. 연결 유지 메시지는 SSH 수준이라 TCP·SSH 는
살아있게 하지만, 원격 셸은 "입력이 없다" 고 보기 때문에 서버의 `TMOUT`(셸 자동 로그아웃)은 막지
못합니다. 그런 서버라면 **문자열 보내기**를 쓰세요. 문자열을 비워두면 화면에 흔적을 남기지 않는
문자를 보냅니다.

연결 유지 메시지 간격은 예전에 10초로 고정돼 있었는데 60초(XShell 기본값)로 바꿨습니다. 응답이
3번 없으면 끊는 동작 때문에, 예전에는 서버가 30초만 조용해도 연결을 끊었습니다. 이제 180초까지
기다립니다 — 로그가 쏟아지거나 서버가 잠깐 바쁠 때 성급하게 끊기지 않습니다.

> 점프(게이트웨이)를 거치는 세션은 중간 홉에 연결 유지가 아예 걸려 있지 않았습니다. 이제 중간
> 홉도 같은 설정을 씁니다 — 중간이 끊기면 전체가 끊기기 때문입니다.

## 📜 스크롤 동작 — 세션마다 설정

세션 편집 > **고급 > 스크롤** 이 생겼습니다.

- **터미널 입출력 시 맨 아래로 스크롤** (기본 끔) — 출력이 올 때마다 화면을 맨 아래로 내립니다.
  꺼두면 스크롤을 올려둔 자리에 머무릅니다
  - **ScrollLock 활성화 시 일시 정지** — 로그가 흐르는 중에 잠깐 멈춰 읽을 때 씁니다
- **키를 누르면 맨 아래로 스크롤** (기본 켬)

지난 버전에서 "스크롤을 올려도 로그가 계속 흘러가던 문제" 를 고쳤는데, 그 동작을 원하는 경우도
있어서 **옵션으로 되살렸습니다.** 기본값은 끔이라 예전처럼 끌려 내려가지 않습니다.

일괄전송 바로 명령을 보낼 때도 "키를 누르면" 과 똑같이 동작합니다. 붙여넣기, Ctrl+Backspace 도
마찬가지입니다.

## 📢 일괄전송 — 보낼 세션 고르기

범위에 **선택한 세션** 이 추가됐습니다. 고르는 방법이 두 가지이고 어느 쪽으로 골라도 같이
반영됩니다.

- **미니탭에 체크박스가 생깁니다** — 실제 탭을 보면서 고르는 쪽이 직관적입니다(연결된 탭만)
- **일괄전송 바의 목록** — 다른 워크스페이스의 세션까지 한눈에 고를 수 있고 전체 선택도 됩니다

범위를 다른 것으로 바꾸면 선택이 지워집니다. 끊긴 세션은 보낼 때 자동으로 빠지지만 선택은 남습니다
— 다시 접속하면 그대로 살아 있는 편이 편하기 때문입니다.

## 📝 터미널 내용을 편집기로 보내기

터미널 우클릭 > **텍스트 편집기로** 에서 **선택 영역 / 전체 / 현재 화면** 을 골라 편집기로
보낼 수 있습니다(선택한 게 없으면 "선택 영역" 은 비활성).

**옵션 > 텍스트 편집기** 에서 열 곳을 정합니다.

| 열 곳 | 동작 |
|---|---|
| 앱 내장 편집기 (기본) | 앱 안에서 읽기 전용으로 보여줍니다. **임시 파일을 만들지 않습니다** |
| OS 기본 프로그램 | 임시 파일로 저장하고 `.txt` 연결 프로그램으로 엽니다 |
| 지정한 편집기 | 경로와 명령줄 옵션을 직접 정합니다. `%FILEPATH` 가 임시 파일 경로로 바뀝니다 |

임시 파일은 지우지 않습니다 — 편집기가 열어둔 동안 지우면 안 되고, 저장해서 남겨두실 수도
있으니까요. 윈도우 메모장에서 한글과 줄바꿈이 깨지지 않도록 저장 방식도 맞췄습니다.

## 📄 마크다운 파일을 읽기 좋게

파일 편집기로 `.md` 파일을 열면 툴바에 **미리보기** 버튼이 생깁니다. VS Code 처럼 편집과 미리보기를
버튼으로 오갈 수 있습니다.

- **코드에 색이 들어옵니다** — 편집기와 같은 색입니다
- **코드블록마다 복사 버튼** — 마우스를 올리면 나타납니다
- **mermaid 다이어그램이 그려집니다** — 잡아 움직이기, 확대·축소(Ctrl+휠 포함), 원래 크기로.
  긴 다이어그램은 처음부터 전체가 보이도록 맞춰서 보여줍니다
- 본문을 드래그해 복사할 수 있고, 우클릭에 복사·전체 선택이 있습니다

미리보기로 넘어가도 편집기는 그대로 살아 있어서, 돌아오면 커서 위치와 되돌리기 기록이 유지됩니다.

## 💬 AI 채팅도 같아졌습니다

위의 코드 색칠 · 코드 복사 버튼 · mermaid 조작이 AI 채팅에도 적용됐습니다. 우클릭에
**선택 영역 복사** 도 추가했습니다 — 긴 답변에서 코드 한 줄만 가져가고 싶을 때가 많으니까요.

> 채팅에서 링크가 진한 남색으로 나와 어두운 배경에서 거의 안 읽혔던 것도 함께 고쳤습니다.

## 📁 세션을 폴더로 복사

세션 우클릭에 **폴더로 복사** 가 추가됐습니다(여러 개 선택해도 됩니다). 기존 "폴더로 이동" 과
나란히 있습니다.

**최상위(루트)로 복사할 때 원본 폴더에 그대로 만들어지던 문제**도 고쳤습니다.

## ⌨ PowerShell 에서 Backspace 를 누르면 줄 전체가 지워지던 문제

로컬 셸 탭에서 Backspace 한 번에 입력한 줄이 통째로 사라졌습니다. PowerShell 이 우리가 보내던
신호를 "줄 앞까지 모두 지우기" 로 해석한 것이었습니다. 로컬 셸에서는 표준 Backspace 신호를
보내도록 바꿨습니다.

SSH 세션은 기존 동작 그대로이고, 세션에서 직접 설정한 값이 있으면 그것이 우선합니다.

## 🔑 비밀번호 저장 확인창에서 Enter 가 안 먹던 문제

비밀번호를 입력해 접속하면 "세션에 저장할까요?" 창이 뜨는데, **Enter 로는 아무것도 되지 않아
매번 마우스로 눌러야 했습니다.** 이제 Enter 로 저장, Esc 로 저장 안 함이 됩니다. 저장 버튼에
포커스가 가서 어느 쪽이 기본인지도 보입니다.
