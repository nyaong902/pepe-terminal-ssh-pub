# v2.6.6

소프트폰 판입니다. **등록 없이 쓰는 단말(non-Reg)**, **발신 헤더 직접 입력**, **UPDATE 처리**가
새로 들어갔고, 교환기가 다른 단말로 거는 호와 교환기가 보내는 ISUP 본문 때문에 끊기던 호를
고쳤습니다. 단말 설정은 이제 **골라서** 내보내고 가져옵니다.
터미널 쪽은 **분할이 균등하게** 열리고, **폴더 우클릭으로 하위 세션을 한꺼번에** 엽니다.

## 📞 등록 없이 쓰는 단말 (non-Reg)

단말 설정(⚙)의 **통화·프로그램**에 `등록 안 함(non-Reg)` 체크가 생겼습니다. 켜면 **REGISTER 를
아예 보내지 않고 INVITE 만** 내보냅니다 — 교환기에 직접 물려 시험할 때 쓰는 방식입니다(C4 트렁크
등). 401/407 로 인증을 요구하면 설정해 둔 비밀번호로 답합니다.

- 상태 표시등이 **파랑**(등록 없이 사용)으로, 등록된 단말(초록)과 구분됩니다
- 그 단말에는 **등록/해제 버튼이 없습니다** — 대신 `non-Reg` 배지가 뜨고, **전체 해제**에서도
  빠집니다. 예전 방식대로 해제가 먹으면 사이드카에서 계정이 사라져 발신만 막혔습니다
- 등록해 쓰던 단말을 non-Reg 로 바꾸면 **교환기에 남은 등록을 내립니다**(REGISTER expires=0).
  안 내리면 교환기는 계속 등록된 줄 알고 그 번호로 착신을 밀어 넣습니다
- 등록이 전제인 프레즌스 PUBLISH·음성사서함 SUBSCRIBE 는 이 단말에서 함께 꺼집니다

> 교환기가 **발신 IP:포트**로 단말을 알아보는 구성이면 `로컬 SIP 포트`를 그 값으로 맞춰야
> 합니다. 다른 프로그램이 그 포트를 쥐고 있으면 임시 포트로 나가 교환기가 모르는 발신자로
> 보고 거절하는데, 이제 그 **바인딩 실패를 알림으로 띄웁니다**(예전엔 로그 한 줄뿐이라
> 놓치기 쉬웠습니다).

## 📤 발신 헤더 직접 입력

`📤 발신 추가 헤더` 에 **「헤더 직접 입력」** 칸이 생겼습니다. 한 줄에 하나씩 `이름: 값` 으로
적으면 INVITE 에 **그대로** 실립니다. 번호만 받아 포맷이 고정된 위 칸들(Diversion/RPID/PAI)로는
낼 수 없는 헤더를 시험할 때 씁니다.

```
P-Early-Media: supported
X-Test-Case: TC-001
```

- 같은 이름을 적으면 위 칸 대신 **여기 적은 것이 나갑니다**(같은 헤더가 두 번 실리면 거절하는
  교환기가 있습니다)
- 빈 줄과 `#`/`;` 로 시작하는 줄은 메모로 보고 건너뜁니다. 이름에 공백·제어문자가 있거나 값이
  비면 버립니다 — 깨진 헤더가 나가면 교환기가 요청 전체를 거절합니다

## 🔄 UPDATE (RFC 3311)

`🔄 UPDATE 처리` 체크(기본 켬)가 생겼습니다. **Allow 에 UPDATE 를 실어** 이 단말이 UPDATE 도
처리한다고 알립니다 — 교환기는 Allow 를 보고 UPDATE 를 보냅니다.

- 받은 UPDATE 는 **200 OK + SDP 답**으로 응답하고, 그 안의 발신번호가 바뀌었으면 **카드의
  "상대" 표시도 따라 바뀝니다**(호전환·대표번호 치환 등). 예전엔 화면이 옛 번호에 멈춰 있었습니다
- 통화 중 버튼 줄의 **🔄** 로 UPDATE 를 직접 보낼 수도 있습니다

## ☎ 끊기던 호 두 가지

### 다른 교환기에 등록된 단말로 걸 때 403

같은 화면에 서로 다른 망의 단말을 두면(예: SKB 6대 + KTC4 6대) **남의 망 도메인으로 INVITE 가
나가** 교환기가 `403 Forbidden`(Q.850 cause=21)으로 거절했습니다.

같은 sipd 안의 다른 단말 도메인을 빌려 쓰던 규칙에 **"같은 교환기일 때만"** 조건을 붙였습니다.
다른 교환기 단말이면 평소대로 자기 도메인으로 걸고, 자기 교환기가 중계(트렁크)로 넘깁니다.
같은 교환기 안의 내선 통화는 예전 동작 그대로입니다.

### 180 Ringing 에 ISUP 본문이 오면 호가 끊기던 문제

상대는 멀쩡히 울리고 있는데 우리 쪽에서 `CANCEL (415 SDP negotiation failed)` 을 던졌습니다.
교환기가 180/183 에 SDP 가 아니라 **ISUP 본문**(`application/isup`)을 실어 보내는데, 엔진이 그걸
SDP 협상 실패로 본 탓입니다. 이제 INVITE 계열 메시지에서 **SDP 도 multipart 도 아닌 본문은
무시합니다**(실단말·다른 소프트폰과 같은 동작). multipart 안에 든 SDP 는 그대로 처리합니다.

### 그 밖에

- 응답이 바로 끊기는 호(403/502 등)에서 **SIP 엔진이 죽던 문제**를 고쳤습니다
- SIP 추적 메시지의 "상대 IP" 가 통화 상대 번호 표시를 덮어쓰던 것
- 단말 설정 카드의 **「⚙ 설정 닫기」** 버튼이 카드 배경에 묻혀 안 보이던 것

## 🗂 단말 설정을 골라서 내보내기 / 가져오기

내보내기는 늘 전부를 내보냈고, 가져오기는 현재 단말·주소록을 **통째로 덮어썼습니다**. 한두 대만
주고받고 싶을 때가 많아 어느 단말을 다룰지 **먼저 고르게** 했습니다(MicroSIP·SSW 소프트폰 공통).

- **내보내기**: 고른 단말만 담고, 그 단말에 묶인 주소록도 함께 넣습니다. 일부만 고르면 파일
  이름에 대수가 붙습니다
- **가져오기**: 기본이 **추가**입니다. 덮어쓰려면 창 안의 `기존 단말을 모두 지우고 가져오기`
  를 체크하세요(체크하면 문구가 빨개지고 버튼도 "덮어쓰기" 로 바뀝니다)
- 최대 대수(100대)를 넘기면 넘치는 만큼은 가져오지 않고 알려 줍니다

## ⊞ 분할이 균등하게 열립니다

같은 칸을 거듭 나누면 1/8 · 1/8 · 1/4 · 1/2 처럼 제각각이었습니다(제보). 나눌 때마다 한 겹씩
감싸 들어가던 것을 **같은 방향이면 옆에 끼워 넣도록** 바꿨습니다 — 몇 번을 나눠도 한 줄에
균등하게 섭니다(좌우 4분할 214 / 214 / 214 / 214px, 예전 190 / 190 / 190 / 285px).

- 경계를 끌어 비율을 정해 둔 자리에서는 **나누는 칸의 몫만 둘로** 쪼갭니다. 손대지 않은 칸의
  너비는 그대로입니다
- 새로 생긴 칸만 1.5배 넓게 나오던 것도 함께 고쳤습니다
- 예전 방식으로 만들어 둔 워크스페이스는 **「패널 비율 균등 정렬」** 한 번이면 펴집니다 —
  비율만 지우던 것을, 겹쳐 쌓인 칸을 한 겹으로 펴도록 했습니다
- 세션 셋 이상을 분할로 열 때 둘째부터 **거꾸로** 열리던 것도 고쳤습니다

## 📂 폴더 우클릭으로 하위 세션을 한꺼번에

세션 우클릭에만 있던 열기 메뉴가 **폴더 우클릭에도** 뜹니다. 하위 세션이 몇 대인지와 어느
워크스페이스에 열지를 고른 뒤 **미니탭 · 좌우 분할 · 상하 분할 · 타일 분할**로 한 번에 엽니다.

- **하위 폴더까지** 재귀로 모읍니다. 접어 둔 폴더 안의 세션도 함께 열립니다
- 여는 순서는 **목록에 보이는 순서 그대로**입니다(끌어 놓아 바꾼 순서 포함)
- 세션이 없는 폴더에는 열기 항목이 뜨지 않습니다
- Ctrl 로 폴더와 세션을 **섞어 고른 경우**도 폴더 안 세션까지 펴서 엽니다. 예전에는 폴더를
  거르고 세션만 세서, 폴더만 고르면 열기 메뉴가 통째로 사라졌습니다
