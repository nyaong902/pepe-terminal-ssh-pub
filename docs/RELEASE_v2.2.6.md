# v2.2.6

## 진단용 버전 업

기능 변경 없음 — v2.2.5의 자동 업데이트 진단 로그(`update-debug.log`)가 실제로 동작하는지 확인하기 위한 테스트용 버전입니다. v2.2.5를 먼저 수동 설치해둔 PC에서 이 버전으로 자동 업데이트를 시도하면, 그 과정이 `%APPDATA%\PePe Terminal(SSH)\update-debug.log`에 기록됩니다.

또한 다른 사람이 작업한 미디어 워크스페이스의 PCAP 기반 RTP 스트림 재생 기능이 포함되었습니다.
