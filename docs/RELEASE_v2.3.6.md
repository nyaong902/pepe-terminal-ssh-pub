# v2.3.6

성능과 안정성을 다듬은 릴리즈입니다. 새 기능은 없고, 실제 사용 중 눈에 걸린 것들을 측정해서 잡았습니다.

## 커서 효과를 켜면 GPU 를 많이 쓰던 문제

세션 > 모양 > 커서에서 프리즘·불꽃·별·하트·동그라미·무지개·파워를 쓰면 GPU 사용률이 크게
오르고, 불꽃과 무지개는 앱 자체가 버벅이기까지 했습니다. 원인이 하나가 아니라 넷이었습니다.

작업 관리자 GPU 사용률 기준, 같은 강도로 연속 타이핑하며 측정한 결과입니다
(일반 블록 커서가 1.5%, 세로로 엔터를 연타하는 최악 조건이 3%):

| 조건 | 이전 | 현재 |
|---|---|---|
| 불꽃 · 가로로 타이핑 | 9.5% | **4% 내외** |
| 파워 · 가로로 타이핑 | 12% | **5% 내외** |
| 불꽃 / 파워 · 엔터 연타 | 9.2% / 12% | **7.8%** |

버벅임도 사라졌습니다 — 86초 측정에서 드롭된 프레임이 48개뿐입니다.

- **이모지를 매 프레임 다시 그리던 문제** — 🔥 나 🌈 같은 컬러 이모지를 파티클마다 매 프레임
  래스터화하고 있었습니다. 측정해보니 그 하나가 렌더러 작업 시간의 87% 였습니다. 이제 같은
  (모양·크기·색) 조합을 한 번만 그려두고 복사해서 씁니다. 파티클이 동시에 너무 많이 쌓이지
  않도록 상한도 함께 두었습니다
- **캔버스가 터미널 전체를 덮고 있던 문제** — 파티클을 그리는 캔버스가 터미널 크기와 같아서,
  파티클이 몇 개뿐이어도 화면 전체를 다시 합성하고 있었습니다. 이제 커서 주변만 덮고
  커서를 따라 움직이며, 그 높이는 커서 효과마다 파티클이 실제로 날아가는 거리를 계산해서
  정합니다. 파티클이 다 사라지면 캔버스를 아예 치워 타이핑을 쉬는 동안은 비용이 없습니다
- **파워 커서의 화면 흔들림** — 흔들림이 터미널 전체를 매 프레임 다시 그리게 만들고 있었습니다.
  이제 흔들리는 동안 화면을 별도 레이어로 올려 옮기기만 하고, 흔들림 폭도 1px 단위로 끊어
  글자가 흐려지지 않습니다
- **프리즘 커서** — 색을 바꾸려고 터미널 테마 전체를 초당 20회 갈아끼우고 있었습니다. 그때마다
  모든 색을 다시 계산하고 전체 화면을 새로 그렸습니다. 이제 커서 색만 직접 바꿉니다

겉모습은 그대로입니다. 파티클이 날아가는 거리·속도·수명·잔상 모두 이전과 같은지 픽셀 단위로
대조해서 확인했습니다.

## 아무것도 안 하는데 GPU 사용률이 계속 움직이던 문제

창을 두 개 띄우고 터미널만 열어둔 채 아무 작업도 하지 않아도 GPU 사용률이 계속 오르내렸습니다.

패널 우측 상단의 활성 표시 점이 원인이었습니다. 점이 커졌다 작아지고 후광이 밝아졌다
어두워지는 애니메이션이 멈추지 않고 돌면서, 화면에 변화가 없어도 매 프레임 그림을 다시 만들게
하고 있었습니다. 65초 동안 재보니 초당 70회 다시 그리고 있었습니다. 패널마다 하나씩이라
창 2개 × 터미널 2개면 그게 네 배가 됩니다.

후광은 그대로 두고 깜빡임만 멈췄습니다 — 활성 상태를 표시한다는 목적은 그대로입니다.

## vimdiff 를 나오면 셸 출력이 초록색으로 물들던 문제

원격에서 `vimdiff` 를 빠져나오면 그 뒤 셸 출력 전체가 초록 배경으로 칠린 채 남고, `ls` 처럼
색을 쓰는 명령이 나올 때까지 계속되던 문제를 잡았습니다. 매번은 아니고 간헐적이었습니다.

vim 의 상태줄 색이 셸로 새어나온 것이었습니다. vim 같은 전체화면 프로그램은 전용 화면으로
전환해서 그리고 나올 때 원래 화면을 복원하는데, 이 서버의 vim 이 나오면서 글자색·배경색을
되돌려주지 않아 그 상태가 그대로 남았습니다. 이제 전용 화면에서 빠져나오는 시점에 색 상태를
초기화합니다.

> 이런 증상이 또 보이면 `printf '\033[m'` 로 즉시 되돌릴 수 있습니다.

## 브라우저 워크스페이스

하위 탭이 많아지면 탭바에 굵고 지저분한 가로 스크롤바가 나타나던 문제를 고쳤습니다.
파일전송 패널의 탭바와 같은 방식으로 바꿨습니다 — 넘칠 때 `‹ ›` 버튼이 나타나고, 마우스 휠로도
좌우로 넘길 수 있습니다. `‹ ›` 와 `+` 는 오른쪽에 고정되어 탭이 많아도 밀려 사라지지 않습니다.

탭 제목도 이전에는 80px 까지 찌그러진 뒤에야 넘쳐서 제목이 전부 `about…` 으로 뭉개졌는데,
이제 읽을 수 있는 폭을 유지한 채 넘어갑니다.
