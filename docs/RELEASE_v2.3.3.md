# v2.3.3

## SQL Tool 세션 관리 — SSH 세션관리 수준으로 독립/강화

SQL Tool(DB 연결)이 SSH 세션에서 완전히 독립된 자체 저장소(`sql-sessions.json`)를 갖게 됐고,
세션 관리 UX가 SSH 세션관리와 동일한 수준으로 강화됐습니다.

- 세션 추가/편집/삭제, 폴더 구조(추가/이름변경/삭제/드래그로 이동), 다중 선택 삭제
- `Ctrl+방향키`로 순서 조정, `Ctrl+C/V`로 세션·폴더 복사/붙여넣기
- 세션 목록 내보내기/가져오기 (JSON)
- 세션 관리창 pin/unpin(자동 숨김) + 크기 조절
- 삭제 확인 등 알림이 네이티브 창 대신 앱 내장 모달로 통일
- SSH 터널을 쓰는 DB 연결이 재연결 시 엉뚱한(터널 안 거친) 주소로 붙던 버그 수정

## 파일전송 — 윈도우 탐색기와 드래그앤드롭 연동

- 파일전송 패널의 파일/폴더를 윈도우 탐색기로 직접 끌어다 놓으면 다운로드되고, 반대로
  탐색기에서 파일전송 패널로 끌어다 놓으면 업로드/복사됩니다. (패키지 설치본에서만 동작 —
  브라우저→OS 파일 드래그앤드롭은 Chromium 이 dev 서버(http://localhost) 실행 환경에서
  보안상 막아 놓은 기능이라 개발 모드에서는 테스트 불가)
- 드래그 시 파일 목록 행 전체가 아니라 파일명(또는 "N개 항목")만 작은 뱃지로 표시되도록 수정
- 원격(SFTP) 파일 삭제가 실패해도(권한 없음 등) 성공으로 잘못 보고되던 버그 수정 — 이제 실패 시
  전송 탭에 에러가 정확히 표시됩니다

## 그 외

- 회사 메신저를 외부 브라우저 대신 앱 안에서 그대로 사용하도록 변경, 내가 보낸 말풍선 우측 정렬
- 브라우저 워크스페이스에서 외부 링크가 포커스 상태에 따라 엉뚱한 곳으로 열리던 문제 수정
- Claude Chat 사이드바 크기 조절 및 브라우저 자동맞춤 개선
- 도구모음 위치(빠른연결 좌/우/상단) 설정이 재시작 후 초기화되던 버그 수정 — `localStorage`
  는 인스턴스별 캐시 격리 때문에 재시작 시 유지되지 않는다는 걸 이번에 확인해서, 해당 설정을
  `ui-prefs`(config.json) 저장 방식으로 옮김
