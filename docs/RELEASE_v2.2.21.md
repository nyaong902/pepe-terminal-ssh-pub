# v2.2.21

## 자동 업데이트에서도 기능 선택 가능 — 설치 프로그램이 아니라 앱에서

지금까지 확인된 사실: 자동 업데이트 중 설치 프로그램의 인터랙티브 페이지(사용자 데이터 삭제 확인, 기능 선택)를 실제로 보여주면 일부 PC에서 설치 창이 아예 안 뜨는 문제가 반복적으로 재현됐습니다(v2.2.16, v2.2.18). 반대로 이 페이지들을 건너뛰면 항상 정상 동작했습니다(v2.2.15, v2.2.20).

그렇다고 기능 선택 자체를 포기하지 않고, **선택하는 위치를 설치 프로그램에서 앱 자체로 옮겼습니다**:

- "재시작하여 설치" 버튼을 누르면, 설치 프로그램이 뜨기 전에 **앱 자체 모달**(VPN/MicroSIP/SIPp/미디어/오피스 체크박스)이 먼저 뜹니다
- 여기서 고른 값을 레지스트리(`HKCU\Software\PePeTerminal\Features`)에 저장한 뒤 설치를 진행합니다
- 설치 프로그램은 자동 업데이트 중엔 여전히 아무 페이지도 안 띄우고, 방금 앱이 저장해둔 값을 조용히 읽어서 적용만 합니다
- 수동 설치(더블클릭)는 지금처럼 설치 프로그램 자체의 페이지가 그대로 뜹니다

**참고**: 이 기능은 이 버전(v2.2.21) 자체가 실행 중이어야 나타납니다. 더 예전 버전에서 자동 업데이트하는 경우엔 이전과 동일하게(이전 선택값 또는 기본 전체설치) 조용히 진행되며, 이 부분은 어떤 앱 업데이트든 피할 수 없는 자연스러운 한계입니다 — 안전하게 성능이 저하될 뿐 문제가 생기지는 않습니다.

번들 선택 값 저장 위치를 레지스트리 `HKLM`에서 `HKCU`로 옮겼습니다(관리자 권한 없이 실행되는 앱이 직접 쓸 수 있도록).
