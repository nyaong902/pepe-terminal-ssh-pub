# 브라우저 워크스페이스

PePe 안에 내장된 웹 브라우저 탭입니다. 별도 프로그램(Chrome/Edge)을 오가지 않고, 터미널·SIP
소프트폰과 같은 창 안에서 EMS 같은 사내 웹 시스템에 바로 접속할 수 있습니다.

## 특징

- 탭 형태로 여러 페이지 동시에 열기
- 주소창 + 앞/뒤 이동 + 새로고침 + 확대/축소
- **직접 연결 / 프록시(VPN) 연결** 모드 선택 — 사내망 접속 시 VPN 경유 여부 지정 가능
- 다른 워크스페이스(터미널, SIP 소프트폰 등)와 같은 창에서 탭으로 전환 가능

## 실사용 예시

SSW CBISS/CDRB 시험·운영 업무에서 웹브라우저로 EMS에 접속해 HVMS 기준 녹취 음원을 확인하는
용도로 실제 사용 중입니다 — 별도 브라우저를 띄우지 않고 터미널 작업 화면 바로 옆 탭에서 처리할
수 있습니다.
