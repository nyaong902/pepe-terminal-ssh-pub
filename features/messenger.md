# PePe Messenger

같은 네트워크 안의 다른 PePe 사용자와 대화·파일 전송을 할 수 있는 내장 메신저입니다.

![PePe Messenger](../screenshots/messenger-01.png)

## 핵심 기능

- **자동 피어 발견**: 같은 네트워크에 있는 PePe 사용자를 자동으로 목록에 표시(온라인/오프라인 상태 포함)
- **텍스트 메시지**: 이모티콘 지원
- **로컬 파일 / 원격 파일 전송**: 대화 상대에게 내 PC의 파일 또는 지금 접속 중인 원격 서버의 파일을 바로 전송
- 별도 서버·계정 없이 사내망 안에서만 동작 — 외부로 데이터가 나가지 않습니다
