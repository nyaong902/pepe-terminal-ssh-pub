# 옵션 (설정)

터미널 동작부터 AI 연동까지 PePe 전반의 설정을 모아둔 화면입니다.

![옵션 대화상자 — 터미널 탭](../screenshots/options-01.png)

## 주요 설정 카테고리

- **터미널**: 클립보드 자동 복사, 여러 줄 붙여넣기 동작, 마우스 오른쪽/가운데 버튼 동작, 글꼴/글꼴 크기
- **세션**: 세션 저장 방식, 로그인 스크립트 관련 옵션
- **워크스페이스**: 탭/패널 동작
- **MCP**: Claude Code MCP 서버 연동 설정
- **디버그**: 문제 진단용 로그/도구
- **단축키**: 키 바인딩 커스터마이즈
- **메신저**: PePe Messenger 관련 설정

설정은 **저장** 버튼을 눌러야 적용되며, **취소**로 되돌릴 수 있습니다.
