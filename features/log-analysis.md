# 로그 분석

로컬/원격 로그 파일을 실시간으로 tail하며 필터링·AI 분석까지 지원하는 워크스페이스입니다.
`.pcap` / `.pcapng` 를 열면 패킷 분석기로 바뀝니다.

![로그 분석 워크스페이스](../screenshots/log-analysis-01.png)

## 핵심 기능

- **실시간 시작**: 파일을 tail -f 방식으로 계속 읽어오며 새 로그 라인 자동 추가
- **다중 필터**: Level / File / 태그 / Function 드롭다운과 메시지·함수·파일명 검색(쉼표로 다중 OR 검색)
- **AI 분석**: 선택한 로그 구간을 Claude에게 바로 물어보고 원인 분석 요청
- **CSV 저장**: 필터링된 결과를 CSV로 내보내기
- **파싱 실패 라인 숨김**: 포맷이 안 맞는 라인을 걸러내고 처리 성공/실패 카운트 표시
- **컬럼 정렬**: 헤더를 누르면 오름차순 → 내림차순 → 원래 순서. Time 은 숫자로 비교하므로
  `10.5` 가 `9.1` 뒤로 갑니다

## pcap 뷰어

`.pcap` / `.pcapng` 파일을 로드하면 Wireshark 방식의 패킷 분석 화면이 됩니다. 창에 파일을
끌어다 놓아도 열립니다(미디어 워크스페이스의 RTP 재생과 둘 중에서 고릅니다).

```
No  Time                        Protocol  Endpoint                       Length  Info
 8  2026-07-24 11:24:32.707007  SIP       172.16.45.18:5060 → …:61698      629  BYE sip:070…
```

- **패킷 목록**: Ethernet / IPv4·IPv6 / TCP·UDP·ICMP·ARP 를 식별하고, SIP 는 요청·응답 첫 줄을
  Info 로 보여줍니다. Protocol·Endpoint 필터와 메시지 검색은 로그 모드와 같습니다
- **필드 트리 + hex/ASCII 덤프**: 행을 고르면 계층별 필드와 원본 바이트가 나옵니다
- **hex ↔ 트리 양방향 연동**: hex 의 바이트에 마우스를 올리거나 클릭하면 그 바이트를 가진
  가장 안쪽 필드를 트리에서 짚고, 접힌 상위 계층을 펼쳐 그 줄로 스크롤합니다. 반대로 트리에서
  필드를 클릭하면 hex 가 그 바이트 줄로 갑니다
- **관련 패킷 표시**: 패킷을 고르면 관련된 패킷을 목록 왼쪽에서 한 줄로 이어 줍니다.
  SIP 는 같은 통화(Call-ID), 그 외에는 같은 대화(양방향 IP:포트) 기준입니다
- **콜플로우 함께 보기**: 참여자를 세로 레인으로 놓은 시퀀스 다이어그램을 표와 나란히 봅니다.
  화살표를 누르면 표가 그 패킷으로 이동하고, 표에서 고르면 화살표가 강조됩니다.
  INVITE·BYE·1xx·2xx·4xx/5xx 를 색으로 구분합니다
- **시간 표시 형식**: 날짜와 시간(기본) · 년/연중일 · 시간 · epoch 초 · 최초 캡처부터 ·
  이전 캡처부터 · 이전 표시부터 · UTC 3종. 표와 콜플로우가 함께 바뀝니다
- **폭 조절**: 표/콜플로우 사이, 트리/hex 사이를 끌어서 나눕니다
- **AI 분석**: 패킷 요약을 그대로 Claude 에게 보낼 수 있고, 답변의 패킷 번호를 누르면 그 행으로
  이동합니다

> 대용량 보호를 위해 한 번에 읽는 패킷 수에 상한이 있습니다. 넘으면 파일 정보 줄에
> "전체 N개 패킷 중 앞부분만 표시(너무 커서 잘림)" 으로 알려줍니다.
