# 로그 분석

로컬/원격 로그 파일을 실시간으로 tail하며 필터링·AI 분석까지 지원하는 워크스페이스입니다.

![로그 분석 워크스페이스](../screenshots/log-analysis-01.png)

## 핵심 기능

- **실시간 시작**: 파일을 tail -f 방식으로 계속 읽어오며 새 로그 라인 자동 추가
- **다중 필터**: Level / File / 태그 / Function 드롭다운과 메시지·함수·파일명 검색(쉼표로 다중 OR 검색)
- **AI 분석**: 선택한 로그 구간을 Claude에게 바로 물어보고 원인 분석 요청
- **CSV 저장**: 필터링된 결과를 CSV로 내보내기
- **파싱 실패 라인 숨김**: 포맷이 안 맞는 라인을 걸러내고 처리 성공/실패 카운트 표시
