# 다국어 지원 (i18n 편집기)

PePe UI에 표시되는 모든 문구를 언어별로 직접 편집할 수 있는 내장 번역 편집기입니다.

![다국어 편집기](../screenshots/i18n-editor-01.png)

## 핵심 기능

- **키-값 편집기**: 화면(namespace)별로 UI 문자열 키와 각 언어 번역을 나란히 놓고 편집
- **AI 번역**: 언어 열마다 있는 "AI (en→ko)" 같은 버튼으로 원문을 자동 번역
- **언어 추가**: `ja, zh-CN, fr` 처럼 콤마로 여러 언어 코드를 한 번에 추가
- **키/값 필터**: 특정 화면이나 문자열만 검색해서 빠르게 수정
- 번역 결과는 즉시 앱에 반영되며 **저장**을 눌러 파일로 확정
